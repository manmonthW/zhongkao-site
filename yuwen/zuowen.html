01

好一场相遇

大连市一模 · 2026年4月 · 第23题（一）
原题
王国维曾说："一切景语皆情语。"自然风景常以无声的姿态，触动人心。你是否也曾在某一刻，与一处风景相遇，收获属于自己的情思与感悟？

请以"好一场相遇"为题目，写一篇文章。
要求：①自选文体（诗歌、戏剧除外）②不少于600字 ③不出现真实人名校名
一、题面拆解
维度分析
题目类型全命题作文（标题不可改）
题眼"相遇"（动词）— 核心动作，需呈现遇见的过程与内心感受
情感定性"好一场"（感叹语气）— 令人赞叹/震撼/难忘，情感积极
引导语限定① 必须有自然风景作触发物
② "某一刻" → 聚焦具体瞬间
③ "收获情思与感悟" → 必须有"悟"
深层暗示"景语即情语" → 写景必须承载情感；"一处" → 单一具体的景致
二、语义四层展开
层级本题具体含义
感官层一处风景的视觉/听觉/触觉/嗅觉之美 — 山河湖海、花草树木、日出落霞
情感层风景触发的情感 — 惊叹、宁静、感动、释然、思念
认知层从相遇中领悟到的道理 — 关于生命、时间、坚韧、渺小与辽阔
哲思层人与自然的关系 — "相遇"的本质：是风景在等我，还是我在寻找风景？
三、立意方向
⚠ 80%考生会写 — 主动避开
  • 旅游看美景感叹"大自然真美"
  • 看日出/日落 → "人生要积极向上"
  • 下雨天看彩虹 → "风雨后见彩虹"
  • 春天看花开 → "生命真美好"
✦ 推荐立意
  1. 困顿时与"小风景"的意外相遇 — 不是名山大川，而是墙缝里的草、被夕阳照亮的旧墙、无名小巷的光影。越"小"越有辨识度。
  2. ★ 风景作为"镜子" — 在风景中看到了某个状态的自己。例如看浪潮冲刷礁石时理解"坚持"；在枯树前接受"放下"。
    推荐理由：景→情→理三层递进，有认知落差
  3. 与同一处风景的"重逢式相遇" — 多年后重返，因成长看到了完全不同的东西。核心：不是风景变了，是我变了。
四、选材与避坑
✦ 推荐素材方向
  • 日常微风景：放学路上小巷黄昏光影、阳台植物突然开花、窗玻璃上的霜花
  • 有时间感的风景：老树 / 旧河 / 石阶 / 古墙 — 承载岁月更容易升华
  • 意外性相遇：不是刻意去看，而是低落/迷茫时偶然撞见
⚠ 绝对避开
  • 名山大川旅游攻略式描写
  • 纯写景无感悟（堆砌修辞但无认知变化）
  • 套用"坚持/努力/不放弃"万能立意
五、结构设计

推荐模型：欲扬先抑型

①开头感叹入题
→
②铺垫低落状态
→
③相遇核心段 40%
→
④触动风景击中我
→
⑤感悟由景入理
→
⑥结尾回扣题目

点题节奏

  • 第1次（开头）：出现"相遇"或变体，明确方向
  • 第2次（③④交汇处）：震撼瞬间用"相遇"呼应
  • 第3次（结尾）：升华 — 相遇的意义超越风景本身
六、语言风格建议
  • 基调：含蓄蕴藉，不铺张不浓烈，有留白感
  • 写景段：精准动词 + 通感，2-3个精准画面胜过10个泛泛比喻
  • 关键技巧：独句成段（转折处）、意象回环（开头结尾同一意象）
  • 忌："啊！多么美丽的景色！"类空洞感叹
满分范文
好一场相遇

那年深秋，我在一条无名的巷子里，遇见了一面旧墙。

初三的十月，模考成绩像一记闷拳。放学后我没有走大路，拐进了学校后面那条从未走过的窄巷。巷子很深，两侧的墙壁斑驳，长着深浅不一的青苔。我漫无目的地走着，脑子里翻来覆去只有一个念头：我是不是不行了。

巷子尽头，一面老墙拦住了去路。

我抬起头，愣住了。

那面墙大约三米高，红砖裸露，水泥剥落，看得出年代久远。可就在墙面中央偏上的位置，一棵榕树的根系从砖缝中探出来，沿着墙面向下蔓延了将近一米，根须紧紧扒住砖面，像无数只手指抓住悬崖。而墙头上方，那棵榕树正张开浓密的枝叶，在夕阳中泛着深沉的绿光。

我站在那里，仰着头，看了很久。

夕阳正把整条巷子染成暖橘色，光线斜斜打在那些裸露的根须上，每一条纹路都清晰可见。那些根系并不粗壮，甚至显得瘦弱，但它们牢牢嵌入砖缝之中，纹丝不动。我伸出手触碰了一下——粗糙、干燥、坚硬，像老人手背上的筋脉。

不知道这棵树用了多少年，才把根扎进这面没有土壤的墙。没有人浇水，没有人施肥，甚至没有人知道它在这里。它只是安静地、一寸一寸地，把自己活成了一道风景。

那一刻，我心里某个紧绷的东西突然松开了。

我想起这些天的焦虑——分数、排名、别人的目光——那些压得我喘不过气的东西，在这面旧墙前突然变得很轻。我一直以为"行不行"是由一次考试定义的，可这棵树告诉我，生长从来不是一蹴而就的事。它不急，不慌，不向任何人证明自己。它只是把根往缝隙里再探深一寸。

好一场相遇。

我后来常常想起那条巷子尽头的光。不是什么壮阔的山河，不是什么名胜古迹，只是一面旧墙、一棵树、一束夕阳。可它让我在十五岁的那个秋天，学会了一件事：

不必急着证明什么。把根扎深，光自然会来。

范文解析

立意说明

采用立意②"风景作为镜子"——在旧墙榕树根系中看到"不急不慌的生长"，对应模考后焦虑，实现认知转变。

结构分析

欲扬先抑：低落(模考) → 偶遇(窄巷) → 震撼(旧墙榕树) → 领悟(生长哲理) → 余韵(把根扎深)

亮点技巧

  • 独句成段×4制造节奏停顿，在转折处强制"慢下来"
  • 触觉细节"粗糙、干燥、坚硬，像老人手背上的筋脉"
  • 视觉细节"根须紧紧扒住砖面，像无数只手指抓住悬崖"
  • 情感克制不说"我感动了"，而是"某个紧绷的东西突然松开了"
  • 意象统一旧墙→根系→夕阳光 贯穿全文

点题位置

  • 第1次：开头"遇见了一面旧墙"（相遇动作）
  • 第2次：倒数第3段"好一场相遇"（独句成段直接点题）
  • 第3次：结尾"把根扎深，光自然会来"（升华式回扣）

低调与高调的辩证 ·《深处有声》

大连市一模 · 2026年4月 · 第23题（二）
原题
有人说，为人处世当低调自持，低处有容，方能海纳百川、静水流深；也有人认为，人生需要适时高调，勇于发声、敢于亮相，方能抓住机遇、成就自我。

对此，你有怎样的联想与思考？请自拟题目，写一篇文章。
要求：①自选角度，自定立意，自选文体（诗歌、戏剧除外）②字迹工整，卷面整洁 ③不少于600字 ④不得套作、抄袭，不得透露个人信息
一、题面拆解
维度分析
题目类型材料作文（自拟题目）
题眼二元对立 ——"低调"与"高调"的辩证关系
情感定性理性思辨，非抒情式。"联想与思考"明确要求有思辨层次
材料解构两个并列观点（非递进）：
低调 → "容""海纳百川""静水流深"（强调积淀包容）
高调 → "发声""亮相""机遇""自我"（强调行动把握）
"适时"一词暗示：高调有前提条件，不是盲目张扬
深层暗示材料用了水的意象（流深/海纳），暗示可以从自然中找辩证关系
二、语义四层展开
层级本题具体含义
感官层低调 = 水的柔顺安静、根在地下无声生长；高调 = 鹰击长空、鼓声震天、花开满树
情感层低调 → 谦逊、稳重、安全感；高调 → 勇气、自信、被看见的渴望
认知层"时"的智慧 — 不是非此即彼，而是懂得何时沉潜积蓄、何时绽放发声
哲思层高低统一 — 真正的"高"源于"低"的积淀；竹子地下三年扎根方能一朝拔节
三、立意方向
⚠ 80%考生会写 — 主动避开
  • 简单选边站："我认为应该低调/高调"
  • 机械折中："有时低调有时高调，具体情况具体分析"
  • 堆砌名人事例（曹操低调、乔布斯高调……）无自己的思考
  • 写成纯议论文但只有论点无生活体验
✦ 推荐立意
  1. "低处扎根，高处开花" — 低调与高调不是对立，而是一株植物的两段生命：地下的沉默是为了地上的绽放。
  2. ★ "静水流深，深处有声" — 表面的"低调"并非沉默无为，是积蓄力量；真正有底气的人，其"高调"不是张扬而是自然流露。
    推荐理由：超越简单二元对立，有辩证深度和层次感
  3. "敢亮相，因为先扎根" — 从"不敢发声"到"敢于亮相"的成长，核心：底气来自沉潜期的积累。适合写叙议结合。
四、选材与避坑
✦ 推荐素材方向
  • 个人成长类：曾因胆怯沉默 → 经过长期准备 → 在关键时刻自信表达（演讲/答辩/展示）
  • 身边人物类：爷爷/手艺人平时沉默寡言，关键时刻一手绝活令人震撼
  • 自然意象类：竹子（地下三年扎根→一朝拔节十米）、蝉（地下数年→一夏高歌）、种子破土
⚠ 绝对避开
  • 纯议论文堆砌名人事例、没有自己的生活体验
  • "低调好"或"高调好"的简单选边
  • 把"高调"写成"炫耀/张扬"来批判（曲解材料原意）
五、结构设计

推荐模型：欲扬先抑型（叙议结合）

→
②沉潜期低调积累
→
③转折需要发声
→
④亮相底气来自积淀
→
⑤感悟低高统一
→
⑥结尾辩证升华

点题节奏

  • 第1次（开头）：引出"低调"与"高调"的困惑/对比
  • 第2次（转折处）：关键时刻沉潜的力量化为发声的底气
  • 第3次（结尾）：回扣自拟标题，升华到辩证统一
六、语言风格建议
  • 基调：沉稳理性，有思辨味但不枯燥，叙述中自然生发议论
  • 忌硬转：不要出现"这件事让我明白了……"式僵硬过渡
  • 推荐：用精准意象代替抽象说理（竹/根/水/种子）
  • 忌：通篇议论文口吻、堆砌名人名言、大段排比空喊
满分范文
深处有声

我曾以为沉默是一种智慧，直到那个夏天，我听见了深处的声音。

初二下学期，学校举办"少年说"演讲比赛，班主任点了我的名。我几乎是本能地摇头——从小到大，我都不是那种站在聚光灯下的人。课堂上我从不举手，小组讨论时我永远是记录者而非发言者。我把这叫做"低调"，甚至觉得沉默本身就是一种姿态。

可班主任说了一句话："你读了那么多书，写了那么多笔记，难道它们只配待在抽屉里？"

我没有回答，但那句话像一枚石子投入深潭。

那天晚上我翻开了书桌抽屉——两年来写的随笔、摘抄、读后感，摞起来有小半尺高。我随手翻开一篇，写的是去年深秋在老家后山看到的一片竹林。我记得当时外公告诉我，毛竹前四年几乎看不见生长，根系却在地下延伸了数十米，到了第五年，一天能拔高三十厘米。

"不是不长，是在下面长。"外公那天说这话时正蹲在竹林边卷旱烟，语气平淡得像在说天气。

我忽然觉得，这两年的阅读和记录，何尝不是我的"地下四年"？那些安静的日子里，我积累了足够多的思考，只是一直没有让它们破土而出。

沉默本身不是智慧，让沉默中长出来的东西被听见——才是。

我用了两周准备演讲稿，题目就叫《深处有声》。上台那天我的膝盖确实在发抖，但当我开口说出第一个故事——外公的竹林、抽屉里的手稿、一个沉默者为什么决定开口——台下安静得不像三百人的礼堂。

讲到最后一段时，我的声音不再颤抖。我说："低调不是软弱，沉默不是无话可说。恰恰相反，正因为在安静中扎够了根，此刻我站在这里，才有了不怕风的底气。"

掌声响起来的那一刻，我明白了一件事。

低调与高调从来不是对立的选择题。它们是同一棵树的两段年轮——根在暗处沉默生长的岁月，和枝叶终于在阳光下舒展的那一天。没有深处的扎根，高处的亮相不过是无根之木的虚张声势；而永远沉潜在地下，再好的根系也只是泥土里的遗憾。

外公的竹林如今比五年前高了两倍。每年春天拔节时，竹节撑开的声音清脆如裂帛，在整个山谷里回响。

那是深处的声音，终于被世界听见。

范文解析

立意说明

采用立意②"静水流深，深处有声"——通过演讲比赛的亲身经历，呈现从"以沉默为智慧"到"让积淀发声"的认知转变，最终达成低调与高调的辩证统一。

结构分析

欲扬先抑（叙议结合）：抗拒发声 → 班主任点拨 → 翻抽屉回忆积淀 → 竹林意象领悟 → 准备并完成演讲 → 感悟升华

亮点技巧

  • 意象贯穿竹林/扎根意象贯穿全文（外公的话→自我领悟→结尾回扣）
  • 叙议融合"沉默本身不是智慧，让沉默中长出来的东西被听见——才是"
  • 独句成段×4在认知转折处制造节奏停顿
  • 细节真实"摞起来有小半尺高""蹲在竹林边卷旱烟"——生活质感
  • 辩证收束结尾不偏向任何一方，将"低"与"高"统一为同一棵树的两段年轮

点题位置

  • 第1次：开头"我听见了深处的声音"（引题）
  • 第2次：演讲稿题目即为《深处有声》（中间呼应）
  • 第3次：结尾"那是深处的声音，终于被世界听见"（升华回扣）

知味

营口市一模 · 2026年4月 · 第23题（一）
原题

第一次校内选拔，我排在倒数第五。

我第一次决定"问路"。

我去找了物理老师。他翻了翻我的笔记本，沉默了几秒，说："你做了很多题，但你有没有想过，为什么这道题要这样设问？出题人想考你什么？"

我愣住了。我从来没想过这个问题。我只是在走——用力地、机械地走。从未停下来问一问：这条路通往哪里？我现在走的方法，是不是最短的那条？

我没发现。但那一刻，我知道了"问路"的价值。

后来的三个月，我不再闷头刷量。做完一组题，我会停下来问自己：这几道题的共同点是什么？我卡在哪一步？是知识漏洞还是思维惯性？遇到不确定的，我去问老师，不是问"怎么做"，而是问"为什么这样做"。

走路与问路，从来不是两件事。

行者无疆。但无疆的前提，是你愿意在路上不断追问。

一百次？我心想，这也太慢了吧？

那句话砸进我脑子里，像石头落进深水。

我忽然想到了自己。我一直想做那把最锐的刀——排名最前、反应最快、分数最高。可刀太锐了会崩口，会断裂。而那块看起来笨拙迟钝的磨刀石，从不着急，从不较劲，只是一下一下地、稳稳地、做好自己该做的事。

有一次她第五遍把视频通话挂断了（本来想接听），我忍不住叹了口气。外婆放下手机，安静地看了我一眼，说："急啥。慢慢来嘛。学不会就再学一遍呗。"

那一瞬间，我愣住了。

我想起上个月模考数学没考好，回家摔了笔，说"我学不会了"。妈妈怎么劝我都不听。可外婆——一个七十三岁、从未摸过智能机的老人，面对一个完全陌生的世界，她的反应不是沮丧，不是放弃，而是"再学一遍呗"。

她的语气平静得像在说天气。

从那以后我教外婆的时候不再叹气了。她按错了，我就说"没事，再来"。她终于学会发语音那天，给我发了一条："囡囡，外婆今天学会啦！"声音里带着笑。

后来外婆学会了刷短视频、在家族群里发早安、用手机拍院子里的花。有一天她兴冲冲给我看她拍的一张照片——歪歪斜斜的，拍的是她窗台上那盆绿萝，配文写着四个字："又长新叶。"

我看着那四个字，忽然想哭。

我教会了外婆用手机。可外婆教会了我的东西更多——面对不会的东西不急躁，不放弃，"再学一遍呗"。还有：值得分享的，从来不是什么大事，而是"又长新叶"这样的小事。

我们都以为成全是单向的——年轻人教老人新技术，老师教学生新知识，父母为孩子铺路。可真正好的关系，从来不是一棵树给另一棵树遮阴，而是两棵树的根在地下悄悄交缠，彼此汲取着对方的养分。

你成全了我的耐心，我成全了你的世界。这才是——相互成全。

范文解析

立意说明

选"教与学的相互成全"——我教外婆用手机（给她打开新世界），外婆教我"再学一遍呗"的从容心态（给我面对挫折的力量）。双向成全自然呈现。

结构分析

双线交织：教外婆（A成全B）→ 外婆一句话触动我（B也成全A）→ 领悟"相互"→ 升华收束

亮点技巧

  • 双向细节既有"我教外婆"的画面，也有"外婆教我"的瞬间——双向对等
  • 细节真实"食指戳屏幕像按门铃""步骤贴手机壳背面""又长新叶"
  • 情感克制"我看着那四个字忽然想哭"——不写哭，只说"想哭"
  • 比喻收束"两棵树的根在地下悄悄交缠"——形象化"相互成全"

点题位置

  • 第1次：开头"是我在教外婆……她也在教我"（暗示相互）
  • 第2次：转折"外婆教会了我的东西更多"（揭示双向）
  • 第3次：结尾"你成全了我的耐心，我成全了你的世界"（完整回扣）

争论见真知 ·《不争不明》

和平区一模 · 2026年4月 · 第22题（二）
原题
班级进行了以"争论方可见真知"为主题的辩论会，会后经验交流时同学们畅所欲言。

宁宁说："真理越辩越明，争论让思想更深刻。"
文文说："争辩非为论输赢，只为靠近更真的答案。"

上面这段对话引发了你怎样的联想和思考？请自拟题目，写一篇文章。
要求：①自选角度，自定立意，自选文体（诗歌、戏剧除外）②字迹工整，卷面整洁 ③不少于600字 ④不得套作、抄袭，不得透露个人信息
一、题面拆解
维度分析
题目类型材料作文（自拟题目）
题眼"争论"的价值——不在输赢，在靠近真理
情感定性理性思辨。两句话都肯定争论的积极面
材料解构宁宁：争论的价值在深化思想
文文：争论的目的是靠近真相（非争输赢）
两者互补，可合一可选一
深层暗示"非为论输赢"→ 材料暗示：好的争论≠吵架/争胜，而是真诚求真。可反面思考"坏的争论"作对比
二、语义四层展开
层级本题具体含义
感官层争论的场景——辩论会上的唇枪舌剑、课堂上的意见碰撞
情感层争论中的紧张、兴奋、被说服时的"恍然"、说服他人时的成就感
认知层"争论"的本质不是对抗，而是思维的碰撞——两块石头碰出火花
哲思层真理从来不是一个人想出来的，而是在不同观点的交锋中逼近的
三、立意方向
⚠ 80%考生会写 — 主动避开
  • 复述辩论会过程→"争论真好"（记叙流水账）
  • 举古人辩论例子→"真理越辩越明"（空洞议论）
  • 把"争论"写成吵架→和好（跑偏）
✦ 推荐立意
  1. "被说服的那一刻最有力量" — 争论中"我输了"反而是收获最大的时刻——放下执念才能看见更大的世界。
  2. ★ "不争不明" — 一次真诚的争论让我发现了自己思维的盲区。争论的价值不在结论，在于让你看到"你没想到的那一面"。
    推荐理由：以个人真实经历切入，认知转变清晰
  3. "争的是理，不是气" — 从"争赢面子"到"争出道理"的转变。
四、选材与避坑
✦ 推荐素材方向
  • 课堂讨论：一道阅读理解题有不同理解，争论后才看到文本深层含义
  • 家庭争论：和父母就某件事有分歧，最终在争论中看到对方的道理
  • 同伴辩论：和朋友就某个问题各执己见，最终互相补充达成更完整的认识
⚠ 绝对避开
  • "争论"写成吵架/人身攻击
  • 纯议论堆砌例子无亲身体验
  • 只写"争论好"不呈现争论的具体过程
五、结构设计

推荐模型：欲扬先抑型（叙议结合）

①开头引出争论
→
②争执各执己见
→
③碰撞核心论辩
→
④转变看到盲区
→
⑤感悟争论的真谛
→
⑥结尾升华回扣

点题节奏

  • 第1次（开头）：引出争论/不同声音
  • 第2次（转变处）："被说服/看到盲区"的瞬间
  • 第3次（结尾）：回扣自拟标题，升华争论的意义
六、语言风格建议
  • 基调：理性冷静中带一点"恍然大悟"的温度
  • 关键：争论过程要有具体的"观点碰撞"——不能只写"我们吵了"
  • 忌：把争论写成吵架；空泛说"真理越辩越明"但没有过程
满分范文
不争不明

那堂语文课上，我和王一帆吵了一架。不对——我们不是在吵，我们是在争。

事情起因很小。老师讲《孔乙己》的最后一课，问了一个问题："孔乙己最后到底死了没有？"

我举手说："死了。文中说'大约孔乙己的确死了'，'的确'二字说明鲁迅的态度很明确。"

王一帆紧跟着举手："我不同意。'大约'说明不确定，鲁迅故意留了模糊空间。他死没死不重要，重要的是没人在乎他死没死。"

我立刻反驳："'大约'和'的确'放在一起，恰恰是反讽——连他的死都只配用'大约'来确认，这不正说明他的确死了，而且死得悄无声息？"

王一帆不服："你只看到了语言层面。可从叙事角度看，鲁迅选择不给出确切答案，是因为他要让读者自己去不安——如果你确定他死了，你反而会松口气。正是这个'不确定'让你一直惦记。"

教室里安静了两秒。

我张了张嘴，本来想继续反驳，但忽然意识到一件事：他说的那个角度，我完全没想到。我一直在字词层面打转，盯着"大约""的确"做语法分析；而他跳出了字面，站到了更高的叙事层面去看这句话的功能。

那两秒钟的安静，是我被"打开"的声音。

老师没有评判谁对谁错，只是笑着说了一句："你们俩刚才的争论，比我准备的课件有营养多了。"

下课后我走到王一帆桌前说："你那个叙事角度我没想到。"他愣了一下，然后说："你的反讽那个分析，其实我也没想到。"

我们互相看了一眼，都笑了。

后来我常常想起那堂课。如果没有那场争论，我会一直觉得自己的理解是"对"的，一直待在自己的认知舒适区里。是王一帆的反驳逼着我跳出来，看到了我思维的边界在哪里。

争论的意义，从来不是分出谁赢谁输。

它的意义是——在你最确信自己正确的时候，有人递给你一个你没想到的角度。你接住了，你就比刚才更大了一点。这个"更大"，靠一个人想是想不出来的。

不争，则不明。

范文解析

立意说明

采用立意②"不争不明"——通过一次课堂上关于《孔乙己》的争论，呈现从"我是对的"到"看到自己的思维盲区"的认知转变。

结构分析

叙议结合：课堂提问→对立观点→交锋升级→沉默被"打开"→课后和解→升华争论的本质

亮点技巧

  • 争论有料不是空泛的"我们各说各话"，而是有具体的文本分析观点对撞
  • 转折精准"那两秒钟的安静，是我被打开的声音"——独句成段
  • 双向尊重下课后互相承认对方的优点——呼应"争的是理不是气"
  • 收束有力"你接住了，你就比刚才更大了一点"——形象化抽象道理

点题位置

  • 第1次：开头"我们不是在吵，我们是在争"（定义争论）
  • 第2次：独句段"争论的意义，从来不是分出输赢"（核心观点）
  • 第3次：结尾"不争，则不明"（标题回扣）
