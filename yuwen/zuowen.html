01

好一场相遇

大连市一模 · 2026年4月 · 第23题（一）
原题
王国维曾说："一切景语皆情语。"自然风景常以无声的姿态，触动人心。你是否也曾在某一刻，与一处风景相遇，收获属于自己的情思与感悟？

请以"好一场相遇"为题目，写一篇文章。
要求：①自选文体（诗歌、戏剧除外）②不少于600字 ③不出现真实人名校名
一、题面拆解
维度分析
题目类型全命题作文（标题不可改）
题眼"相遇"（动词）— 核心动作，需呈现遇见的过程与内心感受
情感定性"好一场"（感叹语气）— 令人赞叹/震撼/难忘，情感积极
引导语限定① 必须有自然风景作触发物
② "某一刻" → 聚焦具体瞬间
③ "收获情思与感悟" → 必须有"悟"
深层暗示"景语即情语" → 写景必须承载情感；"一处" → 单一具体的景致
二、语义四层展开
层级本题具体含义
感官层一处风景的视觉/听觉/触觉/嗅觉之美 — 山河湖海、花草树木、日出落霞
情感层风景触发的情感 — 惊叹、宁静、感动、释然、思念
认知层从相遇中领悟到的道理 — 关于生命、时间、坚韧、渺小与辽阔
哲思层人与自然的关系 — "相遇"的本质：是风景在等我，还是我在寻找风景？
三、立意方向
⚠ 80%考生会写 — 主动避开
  • 旅游看美景感叹"大自然真美"
  • 看日出/日落 → "人生要积极向上"
  • 下雨天看彩虹 → "风雨后见彩虹"
  • 春天看花开 → "生命真美好"
✦ 推荐立意
  1. 困顿时与"小风景"的意外相遇 — 不是名山大川，而是墙缝里的草、被夕阳照亮的旧墙、无名小巷的光影。越"小"越有辨识度。
  2. ★ 风景作为"镜子" — 在风景中看到了某个状态的自己。例如看浪潮冲刷礁石时理解"坚持"；在枯树前接受"放下"。
    推荐理由：景→情→理三层递进，有认知落差
  3. 与同一处风景的"重逢式相遇" — 多年后重返，因成长看到了完全不同的东西。核心：不是风景变了，是我变了。
四、选材与避坑
✦ 推荐素材方向
  • 日常微风景：放学路上小巷黄昏光影、阳台植物突然开花、窗玻璃上的霜花
  • 有时间感的风景：老树 / 旧河 / 石阶 / 古墙 — 承载岁月更容易升华
  • 意外性相遇：不是刻意去看，而是低落/迷茫时偶然撞见
⚠ 绝对避开
  • 名山大川旅游攻略式描写
  • 纯写景无感悟（堆砌修辞但无认知变化）
  • 套用"坚持/努力/不放弃"万能立意
五、结构设计

推荐模型：欲扬先抑型

①开头感叹入题
→
②铺垫低落状态
→
③相遇核心段 40%
→
④触动风景击中我
→
⑤感悟由景入理
→
⑥结尾回扣题目

点题节奏

  • 第1次（开头）：出现"相遇"或变体，明确方向
  • 第2次（③④交汇处）：震撼瞬间用"相遇"呼应
  • 第3次（结尾）：升华 — 相遇的意义超越风景本身
六、语言风格建议
  • 基调：含蓄蕴藉，不铺张不浓烈，有留白感
  • 写景段：精准动词 + 通感，2-3个精准画面胜过10个泛泛比喻
  • 关键技巧：独句成段（转折处）、意象回环（开头结尾同一意象）
  • 忌："啊！多么美丽的景色！"类空洞感叹
满分范文
好一场相遇

那年深秋，我在一条无名的巷子里，遇见了一面旧墙。

初三的十月，模考成绩像一记闷拳。放学后我没有走大路，拐进了学校后面那条从未走过的窄巷。巷子很深，两侧的墙壁斑驳，长着深浅不一的青苔。我漫无目的地走着，脑子里翻来覆去只有一个念头：我是不是不行了。

巷子尽头，一面老墙拦住了去路。

我抬起头，愣住了。

那面墙大约三米高，红砖裸露，水泥剥落，看得出年代久远。可就在墙面中央偏上的位置，一棵榕树的根系从砖缝中探出来，沿着墙面向下蔓延了将近一米，根须紧紧扒住砖面，像无数只手指抓住悬崖。而墙头上方，那棵榕树正张开浓密的枝叶，在夕阳中泛着深沉的绿光。

我站在那里，仰着头，看了很久。

夕阳正把整条巷子染成暖橘色，光线斜斜打在那些裸露的根须上，每一条纹路都清晰可见。那些根系并不粗壮，甚至显得瘦弱，但它们牢牢嵌入砖缝之中，纹丝不动。我伸出手触碰了一下——粗糙、干燥、坚硬，像老人手背上的筋脉。

不知道这棵树用了多少年，才把根扎进这面没有土壤的墙。没有人浇水，没有人施肥，甚至没有人知道它在这里。它只是安静地、一寸一寸地，把自己活成了一道风景。

那一刻，我心里某个紧绷的东西突然松开了。

我想起这些天的焦虑——分数、排名、别人的目光——那些压得我喘不过气的东西，在这面旧墙前突然变得很轻。我一直以为"行不行"是由一次考试定义的，可这棵树告诉我，生长从来不是一蹴而就的事。它不急，不慌，不向任何人证明自己。它只是把根往缝隙里再探深一寸。

好一场相遇。

我后来常常想起那条巷子尽头的光。不是什么壮阔的山河，不是什么名胜古迹，只是一面旧墙、一棵树、一束夕阳。可它让我在十五岁的那个秋天，学会了一件事：

不必急着证明什么。把根扎深，光自然会来。

范文解析

立意说明

采用立意②"风景作为镜子"——在旧墙榕树根系中看到"不急不慌的生长"，对应模考后焦虑，实现认知转变。

结构分析

欲扬先抑：低落(模考) → 偶遇(窄巷) → 震撼(旧墙榕树) → 领悟(生长哲理) → 余韵(把根扎深)

亮点技巧

  • 独句成段×4制造节奏停顿，在转折处强制"慢下来"
  • 触觉细节"粗糙、干燥、坚硬，像老人手背上的筋脉"
  • 视觉细节"根须紧紧扒住砖面，像无数只手指抓住悬崖"
  • 情感克制不说"我感动了"，而是"某个紧绷的东西突然松开了"
  • 意象统一旧墙→根系→夕阳光 贯穿全文

点题位置

  • 第1次：开头"遇见了一面旧墙"（相遇动作）
  • 第2次：倒数第3段"好一场相遇"（独句成段直接点题）
  • 第3次：结尾"把根扎深，光自然会来"（升华式回扣）
02

低调与高调的辩证 ·《深处有声》

大连市一模 · 2026年4月 · 第23题（二）
原题
有人说，为人处世当低调自持，低处有容，方能海纳百川、静水流深；也有人认为，人生需要适时高调，勇于发声、敢于亮相，方能抓住机遇、成就自我。

对此，你有怎样的联想与思考？请自拟题目，写一篇文章。
要求：①自选角度，自定立意，自选文体（诗歌、戏剧除外）②字迹工整，卷面整洁 ③不少于600字 ④不得套作、抄袭，不得透露个人信息
一、题面拆解
维度分析
题目类型材料作文（自拟题目）
题眼二元对立 ——"低调"与"高调"的辩证关系
情感定性理性思辨，非抒情式。"联想与思考"明确要求有思辨层次
材料解构两个并列观点（非递进）：
低调 → "容""海纳百川""静水流深"（强调积淀包容）
高调 → "发声""亮相""机遇""自我"（强调行动把握）
"适时"一词暗示：高调有前提条件，不是盲目张扬
深层暗示材料用了水的意象（流深/海纳），暗示可以从自然中找辩证关系
二、语义四层展开
层级本题具体含义
感官层低调 = 水的柔顺安静、根在地下无声生长；高调 = 鹰击长空、鼓声震天、花开满树
情感层低调 → 谦逊、稳重、安全感；高调 → 勇气、自信、被看见的渴望
认知层"时"的智慧 — 不是非此即彼，而是懂得何时沉潜积蓄、何时绽放发声
哲思层高低统一 — 真正的"高"源于"低"的积淀；竹子地下三年扎根方能一朝拔节
三、立意方向
⚠ 80%考生会写 — 主动避开
  • 简单选边站："我认为应该低调/高调"
  • 机械折中："有时低调有时高调，具体情况具体分析"
  • 堆砌名人事例（曹操低调、乔布斯高调……）无自己的思考
  • 写成纯议论文但只有论点无生活体验
✦ 推荐立意
  1. "低处扎根，高处开花" — 低调与高调不是对立，而是一株植物的两段生命：地下的沉默是为了地上的绽放。
  2. ★ "静水流深，深处有声" — 表面的"低调"并非沉默无为，是积蓄力量；真正有底气的人，其"高调"不是张扬而是自然流露。
    推荐理由：超越简单二元对立，有辩证深度和层次感
  3. "敢亮相，因为先扎根" — 从"不敢发声"到"敢于亮相"的成长，核心：底气来自沉潜期的积累。适合写叙议结合。
四、选材与避坑
✦ 推荐素材方向
  • 个人成长类：曾因胆怯沉默 → 经过长期准备 → 在关键时刻自信表达（演讲/答辩/展示）
  • 身边人物类：爷爷/手艺人平时沉默寡言，关键时刻一手绝活令人震撼
  • 自然意象类：竹子（地下三年扎根→一朝拔节十米）、蝉（地下数年→一夏高歌）、种子破土
⚠ 绝对避开
  • 纯议论文堆砌名人事例、没有自己的生活体验
  • "低调好"或"高调好"的简单选边
  • 把"高调"写成"炫耀/张扬"来批判（曲解材料原意）
五、结构设计

推荐模型：欲扬先抑型（叙议结合）

①开头设置困惑
→
②沉潜期低调积累
→
③转折需要发声
→
④亮相底气来自积淀
→
⑤感悟低高统一
→
⑥结尾辩证升华

点题节奏

  • 第1次（开头）：引出"低调"与"高调"的困惑/对比
  • 第2次（转折处）：关键时刻沉潜的力量化为发声的底气
  • 第3次（结尾）：回扣自拟标题，升华到辩证统一
六、语言风格建议
  • 基调：沉稳理性，有思辨味但不枯燥，叙述中自然生发议论
  • 忌硬转：不要出现"这件事让我明白了……"式僵硬过渡
  • 推荐：用精准意象代替抽象说理（竹/根/水/种子）
  • 忌：通篇议论文口吻、堆砌名人名言、大段排比空喊
满分范文
深处有声

我曾以为沉默是一种智慧，直到那个夏天，我听见了深处的声音。

初二下学期，学校举办"少年说"演讲比赛，班主任点了我的名。我几乎是本能地摇头——从小到大，我都不是那种站在聚光灯下的人。课堂上我从不举手，小组讨论时我永远是记录者而非发言者。我把这叫做"低调"，甚至觉得沉默本身就是一种姿态。

可班主任说了一句话："你读了那么多书，写了那么多笔记，难道它们只配待在抽屉里？"

我没有回答，但那句话像一枚石子投入深潭。

那天晚上我翻开了书桌抽屉——两年来写的随笔、摘抄、读后感，摞起来有小半尺高。我随手翻开一篇，写的是去年深秋在老家后山看到的一片竹林。我记得当时外公告诉我，毛竹前四年几乎看不见生长，根系却在地下延伸了数十米，到了第五年，一天能拔高三十厘米。

"不是不长，是在下面长。"外公那天说这话时正蹲在竹林边卷旱烟，语气平淡得像在说天气。

我忽然觉得，这两年的阅读和记录，何尝不是我的"地下四年"？那些安静的日子里，我积累了足够多的思考，只是一直没有让它们破土而出。

沉默本身不是智慧，让沉默中长出来的东西被听见——才是。

我用了两周准备演讲稿，题目就叫《深处有声》。上台那天我的膝盖确实在发抖，但当我开口说出第一个故事——外公的竹林、抽屉里的手稿、一个沉默者为什么决定开口——台下安静得不像三百人的礼堂。

讲到最后一段时，我的声音不再颤抖。我说："低调不是软弱，沉默不是无话可说。恰恰相反，正因为在安静中扎够了根，此刻我站在这里，才有了不怕风的底气。"

掌声响起来的那一刻，我明白了一件事。

低调与高调从来不是对立的选择题。它们是同一棵树的两段年轮——根在暗处沉默生长的岁月，和枝叶终于在阳光下舒展的那一天。没有深处的扎根，高处的亮相不过是无根之木的虚张声势；而永远沉潜在地下，再好的根系也只是泥土里的遗憾。

外公的竹林如今比五年前高了两倍。每年春天拔节时，竹节撑开的声音清脆如裂帛，在整个山谷里回响。

那是深处的声音，终于被世界听见。

范文解析

立意说明

采用立意②"静水流深，深处有声"——通过演讲比赛的亲身经历，呈现从"以沉默为智慧"到"让积淀发声"的认知转变，最终达成低调与高调的辩证统一。

结构分析

欲扬先抑（叙议结合）：抗拒发声 → 班主任点拨 → 翻抽屉回忆积淀 → 竹林意象领悟 → 准备并完成演讲 → 感悟升华

亮点技巧

  • 意象贯穿竹林/扎根意象贯穿全文（外公的话→自我领悟→结尾回扣）
  • 叙议融合"沉默本身不是智慧，让沉默中长出来的东西被听见——才是"
  • 独句成段×4在认知转折处制造节奏停顿
  • 细节真实"摞起来有小半尺高""蹲在竹林边卷旱烟"——生活质感
  • 辩证收束结尾不偏向任何一方，将"低"与"高"统一为同一棵树的两段年轮

点题位置

  • 第1次：开头"我听见了深处的声音"（引题）
  • 第2次：演讲稿题目即为《深处有声》（中间呼应）
  • 第3次：结尾"那是深处的声音，终于被世界听见"（升华回扣）
03

知味

营口市一模 · 2026年4月 · 第23题（一）
原题
一饭一食里藏着五谷的香，食而知味；一草一木中染着岁月的痕，察而知味；一颦一笑间藏着人情的暖，品而知味。

请以"知味"为题，写一篇作文。
要求：①自选角度，立意自定，文体自选（诗歌、戏剧除外）②字迹工整，书写清楚，卷面整洁 ③不少于600字 ④不得套作、抄袭，不得透露个人信息
一、题面拆解
维度分析
题目类型全命题作文（标题不可改）
题眼"知"（动词）— 由浅到深的感知/领悟过程
情感定性"味"既指感官之味也指人生况味；温暖、沉静的情感基调
材料解构三个并列层次（选一即可）：
①五谷之香（食而知味）
②岁月之痕（察而知味）
③人情之暖（品而知味）
关键动词递进：食→察→品，暗示从感官到精神的深入
深层暗示"知"不仅是"尝到味道"，而是"最终理解了什么是味"。必须呈现认知变化过程
二、语义四层展开
层级本题具体含义
感官层舌尖上真实的味道——某道菜、某种食材、某个厨房的气味
情感层味道背后的情感——家人的爱、故乡的念、陪伴的暖
认知层"知味"的过程——从不在意到珍惜，从日常到理解其深意
哲思层何为"真味"？"至味清欢"——最深的味道往往在最平凡处
三、立意方向
⚠ 80%考生会写 — 主动避开
  • 妈妈做的红烧肉/饺子 → "母爱真伟大"
  • 过年回老家吃年夜饭 → "我知道了家的味道"
  • 生病时喝的粥 → "爱的味道"
✦ 推荐立意
  1. "日常之味的觉醒" — 天天吃却从未注意的某道菜/某种习惯，直到某天缺失了才"知味"。
  2. ★ "至味在平淡处" — 不是大餐名菜，而是外婆的咸菜坛、放学路上的烤红薯、某人做饭时的特定习惯。"知"的核心是从"习以为常"到"恍然珍贵"的转变。
    推荐理由：小切口有辨识度，认知落差清晰
  3. "味道作为时间的刻度" — 同一道菜在不同年龄吃出不同滋味，味觉记录了成长。
四、选材与避坑
✦ 推荐素材方向
  • 日常微食：外婆/奶奶的一道"笨拙"家常菜（豆腐脑、腌菜、手擀面）
  • 动作细节：某个人做饭时的独特习惯/动作（不是味道本身，而是"做"的过程）
  • 消失之味：放学路上消失的某个小摊——消失后才"知味"
⚠ 绝对避开
  • 写满汉全席/名贵食材（大而空）
  • 只写味觉没有感悟（流水账记叙某顿饭）
  • "味"只停留在食物层面，没有升华到情感/认知
五、结构设计

推荐模型：欲扬先抑型

①开头味觉引入
→
②"不知味"曾经忽视
→
③转折缺失/变化
→
④"知味"核心细节段
→
⑤感悟何为至味
→
⑥结尾回扣"知味"

点题节奏

  • 第1次（开头）："味"字自然出现
  • 第2次（转折）：从"不知"到"知"的瞬间
  • 第3次（结尾）："知味"二字完整回扣
六、语言风格建议
  • 基调：温暖质朴，不浓烈不煽情
  • 写味觉时：用通感，味道与记忆/情感联通
  • 推荐：把"做菜的过程"写细（动作、声音、气味），胜过直接描写味道
  • 忌：堆砌美食描写如菜谱；"啊！太好吃了！"式空叹
满分范文
知味

外婆的粥是没有味道的。至少我曾经这样认为。

每个周末被送去外婆家，餐桌上永远是那锅白米粥。不加糖，不加盐，只是清水煮米，熬到米粒开花、汤水黏稠。小时候的我总嘟囔："又是粥，能不能吃点别的？"外婆就笑着，从冰箱里端出一碟自己腌的萝卜干，说："就粥吃，香。"

我不信。粥能有什么味道？

初二那年冬天，外婆住院了。妈妈每天去医院陪护，我一个人在家吃外卖。第一天觉得自由，第二天觉得方便，第三天打开外卖盒的时候，忽然觉得胃里空荡荡的——不是饿，是一种说不上来的"缺"。

周末我去医院看外婆。她靠在病床上，气色不算好，看见我却立刻问："早上吃了没？"我说吃了。她点点头，像是松了口气。

出院那天，外婆做的第一件事不是休息，而是淘米。我站在厨房门口看她——佝偻的背，枯瘦的手，把米在水里轻轻搅了三遍。灶火点着后，她没有离开，就守在锅边，时不时掀开锅盖搅一搅。水汽蒸腾，模糊了她的脸。

那天的粥端上来，我喝了一口。

米香从舌尖蔓延到鼻腔，温热的液体顺着食道滑下去，暖意像一只手从胃底向外推开。我忽然闻到了从前从未注意过的味道——不是什么复杂的调味，就是米本身的甜，是慢火煮出来的那一点点稠。外婆在对面看着我，没说话，只是把那碟萝卜干又朝我推了推。

我低下头，拼命地喝粥，不让眼眶里的东西掉下来。

后来我慢慢明白，那锅粥从来不是"没有味道"。它的味道太淡、太轻、太日常，以至于必须失去一次，才能在舌尖重新辨认出来——那是一个人用几十年的清晨为你守在灶台前的味道。

不加糖，不加盐。只是给你热的、稠的、刚刚好的。

这才是至味。而我终于知味。

范文解析

立意说明

采用立意②"至味在平淡处"——白粥无味→失去后感知→重新"知味"，核心认知转变：最平淡的日常即是最深的爱。

结构分析

欲扬先抑：嫌弃（不知味）→ 外婆住院（缺失）→ 出院后重喝粥（知味瞬间）→ 感悟升华

亮点技巧

  • 情感克制"拼命地喝粥，不让眼眶里的东西掉下来"（不说"感动"）
  • 通感细节"暖意像一只手从胃底向外推开"
  • 意象统一白粥+萝卜干贯穿全文
  • 动作白描"把米在水里轻轻搅了三遍""守在锅边"
  • 独句成段在关键转折处制造节奏停顿

点题位置

  • 第1次：开头"外婆的粥是没有味道的"（反向引出"味"）
  • 第2次：核心段"米香从舌尖蔓延"（味觉觉醒）
  • 第3次：结尾"这才是至味。而我终于知味。"（完整回扣）
04

"马之神"·《无人处，有光》

营口市一模 · 2026年4月 · 第23题（二）
原题
马之可贵，不在其形，而在其神。"神"是什么？是"常随正路，不随非道"的持正，是"竭力驾乘，不厌不倦"的恒心，是"随其情终，能尽其力"的担当，更是在无人涉足处踏出道路、在无人敢前时奋鬣扬鬃的勇敢。

上述材料引发了你怎样的联想和思考？请结合生活实际，自拟题目，写一篇文章。
要求：①自选角度，立意自定，文体自选（诗歌、戏剧除外）②字迹工整，书写清楚，卷面整洁 ③不少于600字 ④不得套作、抄袭，不得透露个人信息
一、题面拆解
维度分析
题目类型材料作文（自拟题目）
题眼"神" — 精神品质，材料给出4个维度：持正、恒心、担当、勇敢
情感定性积极向上、刚健有力
材料解构4个品质递进排列（"更是"标示最高层级）：
持正 → 恒心 → 担当 → 勇敢（最高）
可选其一深入，也可综合体现
深层暗示"不在其形，而在其神"→ 不写外在表现，写内在精神；"结合生活实际"→ 必须有真实生活素材
二、语义四层展开
层级本题具体含义
感官层马奔跑时的力量、鬃毛飞扬的姿态（意象素材）
情感层对某种精神品质的敬佩/向往/被触动
认知层从生活中某个人/事里认识到"持正/恒心/担当/勇敢"的真正含义
哲思层"形"与"神"的关系——真正的力量不在外显，而在精神内核
三、立意方向
⚠ 80%考生会写 — 主动避开
  • 写马的精神→直接说"我们要有恒心/勇气"（空洞议论）
  • 堆砌名人故事（司马迁坚持、爱迪生恒心……）
  • 四种品质全写一遍，浮皮潦草
  • 通篇写马，忘记"结合生活实际"
✦ 推荐立意
  1. 选"勇敢"一点深入 — 材料用"更是"标注最高层，选"在无人涉足处踏出道路"，写一个真正"敢为先"的人或自己的突破。
  2. ★ "不在形，在神" — 外表平凡甚至弱小的人/事物，却拥有惊人的精神力量。核心：反差感。
    推荐理由：切合材料核心句"不在其形而在其神"，有认知落差
  3. "持正"角度 — 在众人皆偏时坚守正道的勇气，写日常中"不随大流"的小事。
四、选材与避坑
✦ 推荐素材方向
  • 身边"不起眼"之人：沉默的同学站出来制止不公、退休邻居坚持做志愿者、代课老师的默默坚守
  • 自己的突破：某次"不被看好"却坚持到底的经历
  • 长辈的闪光：外公/爷爷平凡一生中的某个需要精神力量的瞬间
⚠ 绝对避开
  • 纯写马（偏题）
  • 名人事例堆砌无生活实感
  • 四种品质面面俱到但无一深入
五、结构设计

推荐模型：欲扬先抑型

①开头形与神反差
→
②铺垫外在平凡
→
③核心事件精神爆发 40%+
→
④震撼认知刷新
→
⑤感悟何为"神"
→
⑥结尾升华回扣

点题节奏

  • 第1次（开头）：引出"形"与"神"的关系/设置悬念
  • 第2次（核心段）：精神力量爆发处呼应自拟标题
  • 第3次（结尾）：升华到"神"的真正含义
六、语言风格建议
  • 基调：刚健质朴，有力量感但不空喊
  • 叙事为主：议论只在感悟处点睛，不通篇说理
  • 意象点缀：可用马的意象比喻（"如一匹不惊不惧的马"），但不可通篇比喻
  • 忌：口号式排比、"我们要学习XX精神"式总结
满分范文
无人处，有光

我见过一匹真正的"马"。他不高大、不威武，只是一个弓着背在讲台上写板书的老人。

李老师是我们初一时的数学代课老师。说"代课"，是因为正式老师休产假，他被临时从乡镇中学借调过来。开学第一天，全班四十双眼睛打量他——花白的头发、旧得发亮的夹克、板书时右手微微颤抖。有人在底下传纸条："这老头能教好我们？"

我们以"形"判人，觉得他不够格。

第一周，没人听课。他不发火，只是每天早到二十分钟，把当天的重点用彩色粉笔工工整整抄在黑板侧面。下课后他不走，坐在讲台边等——等那些愿意问问题的人。起初没人来。他就自己改作业，一本一本，错题旁用红笔画出完整的解题步骤。

第二周，有三个同学开始课后留下来问题。第三周，变成七个。因为大家渐渐发现：他讲的每一道题，都比课本多拐一个弯——不是直接给答案，而是带你走到那个"拐弯处"，等你自己转过来。

真正让我震动的是那次月考。成绩出来后，我们班数学均分从年级第六升到了第三。办公室里有老师开玩笑："老李，你可以不走了。"他笑了笑，摆手说："正式老师快回来了，我回去就好。"

走的那天是周五下午。

他没有做任何告别仪式，只是照常上完最后一节课，擦干净黑板，把粉笔盒摆正。临出门时回头说了一句："数学这东西，想不通的时候多画个图。"然后他拎着那个旧公文包，走进了走廊尽头的逆光里。

后来我才知道：他在乡镇中学教了三十一年数学，带过的毕业班没有一届低于区均分。没有论文，没有荣誉证书，没有任何"高调"的东西。他只是年复一年，在那个没多少人关注的乡镇教室里，把每一道题讲透，把每一个学生等到。

那不是什么惊天动地的勇敢，不是在众人面前振臂高呼的壮举。

他的"神"，是在无人注视的角落，把一件事做到骨头里去的那种笃定。

外公曾跟我讲过关于马的话："好马不在跑得快，在走得正、走得久。"

李老师走了之后，我在课桌角贴了一张纸条，上面写着六个字：

无人处，有光。

范文解析

立意说明

采用立意②"不在形，在神"——一个外表平凡的代课老师，以三十一年如一日的笃定诠释"马之神"。核心反差：形的平凡 vs 神的震撼。

结构分析

欲扬先抑：以"形"轻视（花白头发旧夹克）→ 渐渐发现（教学用心）→ 月考验证 → 低调离开 → 知其全貌后震撼 → 升华

亮点技巧

  • 欲扬先抑"这老头能教好我们？"→ 最终均分年级第三
  • 细节白描"每天早到二十分钟""错题旁用红笔画完整步骤""把粉笔盒摆正"
  • 情感克制离别不煽情，"拎着旧公文包走进逆光里"
  • 首尾呼应"我见过一匹真正的马"→ "无人处，有光"
  • 自然扣材外公的话点回"马"的意象，不强扣不僵硬

点题位置

  • 第1次：开头"我见过一匹真正的'马'"（引题设悬）
  • 第2次：倒数第3段"他的'神'是……那种笃定"（扣材料核心）
  • 第3次：结尾"无人处，有光"（标题回扣+升华）
