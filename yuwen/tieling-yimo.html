维度一：试卷结构与分值画像

结构特征

  • 板块完整：覆盖积累运用、整本书阅读、古诗文（默写+诗歌+文言文）、三类现代文（非连续性文本+记叙文+议论文）、写作，与辽宁中考结构完全一致。
  • 辽宁地域素材：积累运用段落以辽宁文博旅游为语境，涉及辽宁省博物馆、沈阳博物馆、锦州北镇、朝阳博物馆、铁岭调兵山等——强烈的地域辨识度。
  • 能力梯度清晰：由识记（字音字形、默写）→理解（词语运用、诗歌对比）→分析（文言文翻译断句、非连续性文本）→综合（记叙文赏析、议论文论证分析）→表达（作文），逐层递进。
  • 写作二选一：命题作文"羁绊" + 材料作文"快与慢"，兼顾情感类与思辨类，与辽宁中考出题模式一致。

维度二：核心考点与知识分布

积累与运用板块

字音字形（guī→瑰, 峥zhēng） 词语运用辨析 标点符号（书名号/引号） 仿写句式

以辽宁文博旅游语段为情境，将字音字形、词语、标点、仿写四类题目整合在同一语境中，体现"情境化命题"趋势。

整本书阅读

《水浒传》人物鉴赏 诗词→人物→性格→情节链

考查方式为"诗词引入 → 识别人物 → 概括性格 → 关联情节"，答案为吴用/智取生辰纲。要求完整的人物分析能力，非简单识记。

古诗文板块

理解性默写（6空） 《饮酒》陶渊明 《游山西村》陆游 《行路难》李白 《醉翁亭记》欧阳修 送别诗对比（岑参vs高适） 文言文对比（小石潭记vs徐霞客游记）

默写线索：以"酒"为主题贯穿六处默写，涵盖淡泊、豪情、希望、旷达四种情感，非机械填空。

古诗对比：甲《白雪歌送武判官归京》（节选）与乙《送李少府贬峡中王少府贬长沙》（高适），均为送别诗但情感基调不同——甲惆怅惜别，乙宽慰勉励。

文言文对比：课内《小石潭记》（柳宗元）与课外《徐霞客游记·游天台山日记》，均写水但着力不同——甲写清澈，乙写气势磅礴。

现代文阅读板块

非连续性文本（红色经典主题） 记叙文（李清学英雄事迹） 议论文（"虚己以游世"）

非连续性文本：三则材料（评论+调查数据表+影视剧分析），考查信息筛选、说明方法、概括归纳。红色经典题材体现"立德树人"价值导向。

记叙文：人民日报通讯《关键时刻，他挺身而出》——追记辽宁建昌县村支书李清学防汛牺牲事迹。考查景物描写作用、细节能否删除、拟小标题、人物品质分析、挽联补写。强烈的辽宁本土+时代主旋律特色。

议论文：《何不"虚己以游世"》，庄子哲理散文。考查中心论点提取、论证思路梳理、论证方法、"虚己"含义理解、句段作用分析。

写作

命题作文：羁绊 材料作文：快与慢 二选一 600字以上

两道作文题覆盖情感类（羁绊→人际/物我情感联结）和思辨类（快与慢→辩证思维），给不同类型考生以选择空间。

模块评估卡

模块A：积累运用

覆盖题位：Q1-Q4（约8分）

风险等级：低

失分点："今世来生"词语使用判断（答案C不恰当）、标点符号规范细节。

提分抓手：字音字形基础过关 + 标点符号规范记忆 + 仿写句式练习。

模块B：整本书阅读+默写

覆盖题位：Q5-Q6（约11分）

风险等级：中

失分点：名著人物诗词对应不准；默写中"采菊东篱下""长风破浪会有时"等易写错字。

提分抓手：《水浒传》核心人物卡片（外号-性格-关键情节）；60篇必背古诗文理解性默写专练。

模块C：古诗文阅读

覆盖题位：Q7-Q12（约17分）

风险等级：高

失分点：诗歌情感对比分析不够精准；文言文实词一词多义（"从"=跟随 vs 全）；课外文言文翻译不准；断句技巧薄弱。

提分抓手：课内文言文120个核心实词卡片；课外文言文每日一练（优先游记类）；断句先找动词主语。

模块D：现代文阅读

覆盖题位：Q13-Q24（约36分）

风险等级：高

失分点：非连续性文本信息筛选遗漏；记叙文"景物描写作用""能否删除"答题模板不完整；议论文论证思路表述不规范。

提分抓手：三类文体答题模板固化训练。

维度四：命题特征与趋势研判

本卷命题逻辑呈现"地域根植 + 价值引领 + 能力递进 + 情境整合"的特征，可提炼以下命题DNA：

  1. DNA-1 辽宁地域深度嵌入：积累运用以辽宁文博为语境（辽宁省博物馆、沈阳博物馆、锦州、朝阳、铁岭调兵山）；记叙文选取辽宁建昌县村支书防汛牺牲事迹。地域素材不是点缀，而是深度融入考查情境。
  2. DNA-2 立德树人价值导向：红色经典（非连续性文本）+ 英雄事迹（记叙文）+ 传统哲理（议论文庄子"虚己"），三篇现代文分别对应爱国主义、社会主义核心价值观、传统文化传承——价值覆盖全面。
  3. DNA-3 课内外对比阅读：诗歌（课内岑参 vs 课外高适）、文言文（课内《小石潭记》vs 课外《徐霞客游记》），均为同题材跨文本对比。这是辽宁近年命题稳定趋势。
  4. DNA-4 情境化整合命题：积累运用四道题整合在同一辽宁文博语段中，非碎片化出题。情境化已成为命题标配。
  5. DNA-5 主题串联默写：以"酒"为主题贯穿六处默写空，要求理解诗句情感后填写，非机械背诵。
  6. DNA-6 记叙文小标题+挽联创新题：Q18 要求拟小标题并说明理由（概括+元认知），Q20 要求补写挽联（对仗+内容理解），属于辽宁特色题型。
  7. DNA-7 议论文"虚己"仿写：Q23(2)要求仿照教师/诗人的"虚己"示例，补写另一种"虚己"情境——将阅读理解与语言运用融合考查。
  8. DNA-8 写作二选一覆盖两类思维："羁绊"考情感表达（叙事+抒情），"快与慢"考辩证思维（议论+说理），给不同擅长方向的学生以公平选择。

趋势判断：辽宁中考语文将持续强化"情境化命题 + 课内外对比 + 辽宁素材融入 + 价值导向"四大特征。纯记忆题占比持续下降，理解与综合表达题占比上升。课外文言文的选材偏好游记类，课外诗歌偏好同题材（送别/咏物/写景）对比。

二、易错预警表

高频易错点典型表现纠偏策略
默写写错字"采菊东篱下"写成"彩菊"；"长风破浪会有时"漏字理解性记忆：先理解诗句意思，再默写。每天限时默写+对照批改

四、记叙文阅读万能答题模板

"景物描写作用"四步法：

  • ①交代了__________的环境背景（内容层面）
  • ②渲染了__________的气氛/烘托了人物__________的心情（情感层面）
  • ③为下文__________作铺垫/推动情节发展（结构层面）
  • ④衬托/突出了人物__________的品质（人物层面）

"能否删除"三步法：

  • ①表态：不能删除
  • ②分析删除对象的作用（内容上写了什么 + 表达效果上起了什么作用）
  • ③删除后的后果（如删去则不能体现__________，使文章__________）

议论文"论证思路"模板：

  • 首先，作者通过__________（论证方法）论证了__________（分论点）；
  • 接着，运用__________（论证方法），从__________角度进一步论证__________；
  • 最后，得出__________的结论。
