# 化学单卷深度分析 Skill（五维分析模型）

> 适用于：辽宁中考化学模拟卷逐卷分析
> 输入：OCR文本 + 答案（如有）
> 输出：单张HTML页面，内嵌CSS，无外部依赖

---

## 一、分析框架总览

化学试卷分析的核心特征：
- **14题50分**：题量最少但每题分值极高，非选择题单题9-11分
- **非选择题占80%**：4道大题40分是绝对主战场，选择题仅10分
- **化学方程式是灵魂**：几乎每道非选择题都要求书写化学方程式
- **气体制取是铁律**：Q11实验探究题11/11套卷考气体制取（CO₂/O₂）
- **科普阅读不可预测**：Q13题材每套不同（脑机接口/锂电池/碳纤维/荔枝保鲜……），考的是信息提取能力
- **与物理合卷150分钟**：化学建议用时约55分钟

五个维度：

| 维度 | 名称 | 核心问题 | 化学特色 |
|------|------|----------|----------|
| 一 | 骨架图·结构解剖 | 卷子长什么样？ | 14题固定结构（选择10+非选择4），非选择题80% |
| 二 | 题型谱·逐题档案 | 每道题考什么？ | 逐题标注：知识点 + 核心方程式 + 能力维度 + 难度 |
| 三 | 考点标签·知识定位 | 知识怎么分布？ | 四大主题分值 + 教材章节映射 + 高频考点对照 |
| 四 | 命题DNA·命题解码 | 命题人想考什么？ | 命题观察逐条提炼 + 科普阅读题材分析 + 计算题定位 |
| 五 | 作战地图·行动转化 | 怎么拿分？ | 优先级排序 + 必背方程式 + 易错预警 + 分数规划 |

## 六、维度五：作战地图·行动转化

### 6.1 优先级建议

| 优先级 | 任务 | 目标分值 | 说明 |
|--------|------|----------|------|
| P1 | 实验室制取气体 | ~15分 | CO₂/O₂制取全流程（药品→方程式→装置→收集→检验） |
| P2 | 化学方程式书写与计算 | ~10分 | 必背方程式+计算模板（比例式法） |
| P3 | 酸碱盐核心反应 | ~10分 | 指示剂+复分解反应条件+中和反应 |
| P4 | 科普阅读答题技巧 | ~8分 | 先读问题再读文章+关键词定位+微粒观点必答 |

### 6.2 必背化学方程式清单（化学独有）

按非选择题出题方向分类：

**Q11 气体制取类：**
- CO₂：CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑
- O₂（加热）：2KMnO₄ →(加热) K₂MnO₄ + MnO₂ + O₂↑
- O₂（催化）：2H₂O₂ →(MnO₂) 2H₂O + O₂↑

**Q12 能源/工业类（高频）：**
- 电解水：2H₂O →(通电) 2H₂↑ + O₂↑
- 合成氨：N₂ + 3H₂ ⇌(高温高压催化剂) 2NH₃
- 甲醇合成：CO₂ + 3H₂ →(催化剂) CH₃OH + H₂O
- 氢气燃烧：2H₂ + O₂ →(点燃) 2H₂O

**Q14 酸碱盐类：**
- 中和反应：NaOH + HCl = NaCl + H₂O
- 碳酸盐检验：Na₂CO₃ + 2HCl = 2NaCl + H₂O + CO₂↑
- 金属+酸：Fe + 2HCl = FeCl₂ + H₂↑

### 6.3 易错预警表

| 题号/类型 | 易错点 | 防范措施 |
|-----------|--------|----------|

化学高频易错点类型：
- 化学方程式未配平（系数漏写/错写）
- 化学方程式条件符号遗漏（↑↓/点燃/加热/催化剂）
- 离子符号书写错误（2SO₄²⁻ 不是 SO₄²⁻₂）
- 元素符号大小写（Au 不是 AU）
- 溶液稀释计算公式搞反（m₁w₁ = m₂w₂）
- 化学方程式计算未用相对分子质量而用相对原子质量
- 气体收集方法选错（CO₂用向上排空气法，不能用排水法）
- 干燥剂选错（干燥CO₂不能用NaOH，会反应）
- "质量守恒"题忽略气体逸出导致质量减小
- 科普阅读题答非所问（未从文中提取信息，而是凭已有知识作答）

### 6.5 计算题答题模板

**化学方程式计算（Q14常考）：**
1. 设未知数：设需要XX的质量为x
2. 写方程式：（配平！标条件！）
3. 标相对分子质量：在相关物质下方标注
4. 列比例式：已知量/已知相对分子质量 = x/未知相对分子质量
5. 解方程求x
6. 答：需要XX的质量为Xg

**溶液稀释计算（Q11常考）：**
- 公式：m浓 × w浓 = m稀 × w稀
- 需加水质量 = m稀 - m浓

## 十、质量铁律（每次生成必须遵守）

1. **先冻结模板再动手**：开始分析前，确认本 Skill 的五维结构、表格字段、标签体系完全一致。不允许中途自行删减维度、合并表格、省略字段。每套卷的输出结构必须与模板严格对齐，否则跨卷对比时会漂移。

2. **所有数据从 OCR 源文本获取**：逐题考点、答案、分值、化学方程式等所有信息必须从 OCR 文本和答案原文中逐题提取，不允许凭印象编造、推测或复用其他试卷的数据填充。OCR 不清晰的内容必须标注 `[OCR待验证]`，不能为了速度跳过或猜测。化学方程式必须逐个从原卷核实，不能凭记忆默写。

3. **逐题不可跳过**：14道题每道都必须出现在维度二的逐题档案中，不允许"选择题略"等省略写法。选择题10道逐题列出，非选择题4道逐小问列出（含答案要点和涉及的化学方程式）。

4. **交付前双重检查**：
   - **单份完整性门禁**：五个维度是否齐全？逐题表是否覆盖全部14题？化学方程式清单是否完整？计算题步骤是否列出？高频考点对照是否完成？
   - **跨文件一致性检查**：本卷的主题分值统计是否与首页 index.html 和横向对比 duibi.html 中的数据一致？导航链接是否正确？
