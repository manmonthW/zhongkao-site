# 历史单卷深度分析 Skill（五维分析模型）

> 适用于：辽宁中考历史模拟卷逐卷分析
> 输入：OCR文本 + 答案（如有）
> 输出：单张HTML页面，内嵌CSS，无外部依赖

---

## 一、分析框架总览

历史试卷分析的核心特征：
- **开卷考试**：与道法合卷150分钟，满分70分，可翻书——但翻书找不到的是「材料整合能力」和「论述表达能力」
- **时空是骨架**：从上古到当代、从中国到世界，必须标注每题的时空坐标
- **四大板块**：中国古代史 / 中国近现代史 / 世界史 / 跨模块综合
- **论述题是分水岭**：Q19(4) 固定6分二选一论述，结构比内容重要
- **19题固定结构**：选择15题30分 + 综合4题40分

五个维度：

| 维度 | 名称 | 核心问题 | 历史特色 |
|------|------|----------|----------|
| 一 | 试卷结构与分值画像 | 卷子长什么样？ | 选择15题+综合4题，中国史vs世界史占比 |
| 二 | 核心内容与主线逻辑 | 考了哪些知识？ | 选择题考点标签 + 综合题四大主题轴 |
| 三 | 逐题映射与模块评估 | 每题考什么能力？ | 逐题表（知识/能力/教材定位）+ 四模块风险评估 |
| 四 | 命题DNA与趋势研判 | 命题人想考什么？ | 命题DNA逐条提炼 + 趋势判断 |
| 五 | 提分优先级与落地方案 | 怎么拿分？ | 优先级排序 + 易错预警 + 分数规划 + 论述模板 |

## 二、维度一：试卷结构与分值画像

### 输出内容

1. **基本参数 KPI 卡片**（4个）
   - 选择题（推定）：30分
   - 综合题（Q16-Q19）：40分
   - 中国史占比：约XX%
   - 世界史占比：约XX%

2. **综合题分值明细**

| 题号 | 分值 | 主题方向 |
|------|------|----------|
| Q16 | 9-10分 | 通常为中国古代史 |
| Q17 | 9-12分 | 通常为中国近现代史 |
| Q18 | 8-9分 | 通常为中共党史/新中国 |
| Q19 | 11-12分 | 世界史+论述题6分 |

Q19(4) 论述题固定6分，二选一，4级评分。

3. **结构特征总结**（ul列表）
   - 时序跨度：从XX到XX
   - 主题线索：本卷的核心主线
   - 能力梯度：识记辨析→材料整合→跨时空论证→价值表达

### 关键数据参考（8套卷统计）

| 板块 | 均值占比 | 均值分值 |
|------|----------|----------|
| 中国近现代史 | 38% | ~27分 |
| 中国古代史 | 24% | ~17分 |
| 世界史 | 21% | ~15分 |
| 跨模块综合 | 17% | ~12分 |

## 三、维度二：核心内容与主线逻辑

### 3.1 选择题考点标签云

用 `.tag` 标签样式列出所有选择题涉及的考点关键词，如：
- 原始社会→奴隶社会过渡
- 中央集权形成主线
- 唐代文物与社会风气
- 戊戌变法与新式学堂
- 历史解释辨析
- 二战转折
- 冷战格局
- ……

### 3.2 综合题四大主题轴

每道综合题用一句话概括其主题轴，格式：
- **Q16"主题名"**：将XX、XX、XX整合为"XX与XX"的主题。
- **Q17"主题名"**：从XX到XX，强调"XX与XX"。
- **Q18"主题名"**：XX、XX、XX，体现"XX与XX"的历史逻辑。
- **Q19"主题名"**：XX串联XX，最终落脚XX论述。

### 3.3 论述题主题归类

标注本卷Q19(4)的两个选项属于哪个大类：
- 制度/改革类（商鞅变法、明治维新、改革开放）
- 文化/思想类（四大发明、百家争鸣、文艺复兴）
- 统一/合作类（秦统一、港澳回归、联合国家宣言）
- 人民/民族类（法国大革命、五四运动、美国独立战争）

## 四、维度三：逐题映射与模块评估

### 4.1 逐题映射表

| 题号 | 分值 | 知识维度 | 能力维度 | 教材定位 |
|------|------|----------|----------|----------|

**能力维度**分类（历史特有）：
- 时序判断（朝代/年代排序）
- 概念辨析（历史解释 vs 历史事实）
- 史实匹配（人物-事件-意义对应）
- 材料提取（从文字/图片/数据中提取信息）
- 跨朝代关联（不同时期同类事件比较）
- 因果解释（原因-过程-结果-影响）
- 图表数据解读（产量/比例/趋势）
- 主题归纳（从散点材料提炼主线）
- 史论结合（用史实支撑观点）
- 观点建构与结构化写作（论述题）

**教材定位**参考：
- 七上：中国古代史（远古-秦汉）
- 七下：中国古代史（隋唐-明清）
- 八上：中国近代史（鸦片战争-新中国成立前）
- 八下：中国现代史（新中国成立-当代）
- 九上：世界古代史+近代史（文明起源-工业革命）
- 九下：世界现代史（一战-当代）

### 4.2 四模块风险评估卡（grid-2双栏布局）

**模块A：古代中国与文明根基**
- 覆盖题位 + 分值
- 风险等级
- 失分点：制度术语混淆/朝代定位不准/人物成就张冠李戴
- 提分抓手："朝代-制度-人物-成就"四格卡片

**模块B：近代中国救亡与探索**
- 失分点：改革目标与革命纲领边界不清/历史结论套话化
- 提分抓手："事件背景-主张-效果-局限"四步模板

**模块C：中共党史与新中国发展**
- 失分点：精神类题目空泛抒情/改革开放论证单薄
- 提分抓手：每一主题至少"1定义+2史实+1现实意义"

**模块D：世界史与现代化视角**
- 失分点：世界史概念孤立记忆/缺乏与中国史的比较联系
- 提分抓手：按"制度-革命-国际格局-福利国家"构建专题图谱

## 五、维度四：命题DNA与趋势研判

### 输出格式

开头一句话概括命题逻辑特征。

逐条提炼命题DNA（DNA-1 到 DNA-N，通常6-8条）。

### 命题DNA常见类型（8套卷归纳）

| DNA类型 | 说明 | 出现频率 |
|---------|------|----------|
| 主线统摄 | 散点考点围绕"国家发展与社会进步"主线聚合 | 8/8 |
| 古今贯通 | 古代制度文明与近现代转型并置 | 8/8 |
| 中外对照 | 中国史与世界史双向参照 | 7/8 |
| 史料驱动 | 文字材料与数据材料并重 | 8/8 |
| 价值导向 | 民族独立/改革创新/信仰力量等核心价值 | 8/8 |
| 能力递进 | 从识记到论述，题序构成能力爬坡 | 8/8 |
| 现实关联 | 社会保障/科技创新/道路选择等当代议题 | 7/8 |
| 论述开放 | Q19(4)二选一"同核多路"开放论证 | 8/8 |
| 辽宁地方史 | 九一八/辽沈战役/鞍钢/红山文化等 | 5/8 |

末尾一段「趋势判断」。

## 六、维度五：提分优先级与落地方案

### 6.1 优先级建议表

| 优先级 | 任务 | 目标 | 建议周期 |
|--------|------|------|----------|
| P1 | Q19(4)论述专项（双模板） | 6分题稳定4-5分 | 连续7天每天1题 |
| P2 | Q17数据+制度综合训练 | 9分题稳定6-7分 | 5天隔天1组 |
| P3 | Q18主题证据链训练 | 9分题稳定7分+ | 5天按主线循环 |
| P4 | 选择题易混点清单复盘 | 控制在错2题以内 | 每日20分钟 |

### 6.2 易错预警表

| 高频易错点 | 典型表现 | 纠偏策略 |
|------------|----------|----------|

历史高频易错点类型：
- "历史解释"与"历史事实"混淆（含评价词/因果判断的=历史解释）
- 土地制度时序混乱（天朝田亩制度/解放区土改/建国后政策混写）
- "信仰力量"类题目空泛抒情（每段必须"事件+作用+结果"三要素）
- 世界史与中国史割裂（训练"世界经验-中国道路"对照句式）
- 二选一论述选题失误（考前明确主攻主题）
- 朝代制度张冠李戴（科举/三省六部/行省制等归属朝代）
- 近代探索主线顺序错乱（洋务→戊戌→辛亥→新文化→五四）

### 6.3 目标分数规划表

| 分数档 | 选择题目标 | 材料题目标（Q16-19） | 关键策略 |
|--------|-----------|---------------------|----------|
| 冲刺65+ | 27-30 | 31-35 | 论述满结构+材料题要点全覆盖+术语规范 |
| 稳定55-64 | 24-27 | 26-32 | 先保Q16/Q18，再突破Q17数据题与Q19论述 |
| 保底45-54 | 20-24 | 20-28 | 选择题错因清零，材料题"抄材料关键词+短句作答" |

### 6.4 Q19(4) 论述6分模板

**万能结构（考场直接套用）：**
- **观点句**：XX是推动社会发展的关键动力。
- **史实1**：结合XX案例，说明XX。（中国史或世界史）
- **史实2**：结合XX案例，说明XX。（另一个时期/地区）
- **总结句**：坚持XX，国家才能实现XX。

**4级评分标准**：
- 6分：观点明确+2个以上史实+逻辑清晰+总结升华
- 4-5分：观点明确+1-2个史实+基本逻辑
- 2-3分：有观点但史实不足或逻辑混乱
- 0-1分：无观点或完全偏题

### 6.5 辽宁地方史速查

| 考点 | 关键信息 |
|------|----------|
| 九一八事变 | 1931.9.18，沈阳北大营/柳条湖→局部抗战开始 |
| 辽沈战役 | 1948.9-11，锦州→长春→沈阳→解放东北全境 |
| 鞍钢 | 一五计划重点项目→新中国工业化起步 |
| 红山文化 | 牛河梁/玉猪龙→中华文明多元一体 |
| 振兴东北 | 2003年提出→区域发展战略 |

## 八、分析流程 Checklist

- [ ] 1. 确认试卷结构（19题/70分？综合题各自分值？）
- [ ] 2. 逐题标注：知识维度 + 能力维度 + 教材定位 + 答案
- [ ] 3. 统计中国古代史/近现代史/世界史/跨模块分值占比，与8套卷均值对比
- [ ] 4. 提取选择题全部考点关键词（标签云）
- [ ] 5. 概括综合题四大主题轴（每题一句话）
- [ ] 6. 确认Q19(4)论述题的两个选项及其主题归类
- [ ] 7. 完成四模块风险评估（失分点+提分抓手）
- [ ] 8. 提炼命题DNA（6-8条）
- [ ] 9. 检查是否涉及辽宁地方史
- [ ] 10. 制定优先级建议 + 易错预警 + 分数规划
- [ ] 11. 编写论述题模板（针对本卷两个选项）
- [ ] 12. 生成HTML页面，检查导航链接

## 九、质量铁律（每次生成必须遵守）

1. **先冻结模板再动手**：开始分析前，确认本 Skill 的五维结构、表格字段、标签体系完全一致。不允许中途自行删减维度、合并表格、省略字段。每套卷的输出结构必须与模板严格对齐，否则跨卷对比时会漂移。

2. **所有数据从 OCR 源文本获取**：逐题考点、答案、分值、时空坐标等所有信息必须从 OCR 文本和答案原文中逐题提取，不允许凭印象编造、推测或复用其他试卷的数据填充。OCR 不清晰的内容必须标注 `[OCR待验证]`，不能为了速度跳过或猜测。

3. **逐题不可跳过**：19道题每道都必须出现在维度三的逐题映射表中，不允许"选择题1-15略"等省略写法。选择题15道逐题列出考点和答案，综合题4道逐小问列出。

4. **交付前双重检查**：
   - **单份完整性门禁**：五个维度是否齐全？逐题表是否覆盖全部19题？四模块评估是否完成？论述模板是否编写？
   - **跨文件一致性检查**：本卷的板块分值统计是否与首页 index.html 和横向对比 duibi.html 中的数据一致？导航链接是否正确？
