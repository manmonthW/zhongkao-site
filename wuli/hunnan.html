4.2 逐题实验深度分析

Q18 · 水沸腾前后温度变化的特点（热学 · 探究性实验 · ~6分）

实验目的：探究水在沸腾前后温度变化的特点

核心器材：铁架台、酒精灯、烧杯、温度计、纸板（带孔）、秒表

实验方法：观察法 + 图像法

考查能力点：

子问考查内容答案易错点
(1)纸板上额外开个小孔的目的使烧杯内外气压相等不能答"散热"或"观察"
(2)温度计放入热水中立刻读数，测得温度偏差偏大（温度计未充分热平衡，示数偏高→实际应偏小，但此处温度计从室温放入热水，液柱还未升到位→偏小）[OCR待验证] 答案：偏大需区分"从冷到热"还是"从热到冷"
(3)沸腾时的现象图 + 温度变化特点图(a)（大量气泡上升变大）；不变沸腾前气泡上升变小(b)，沸腾时气泡上升变大(a)
(4)牛奶80-85℃"翻滚冒气泡"是否沸腾 + 理由没有；温度还在上升，没有达到沸点（沸腾特征：持续吸热温度不变）不能仅答"温度低"，需说明沸腾判据

创新要素：第(4)问拓展到牛奶沸点测量，考查学生对"沸腾判据"的深层理解——翻滚≠沸腾，必须温度不变才是沸腾。

Q19 · 凸透镜成像规律（光学 · 探究性实验 · ~6分）

实验目的：探究凸透镜成像的规律

核心器材：光具座、凸透镜、"F"形发光物体、光屏、水晶球（引入情境）

实验方法：控制变量法 + 观察法

考查能力点：

子问考查内容答案易错点
(1)挑选透镜：甲乙对着太阳光，选哪个(b)——会聚透镜（凸透镜）能在光屏上形成最小最亮光斑凹透镜不能会聚成点
(2)调节高度使发光物体和光屏中心在透镜的___上同一高度（主光轴）；使像成在光屏中央"同一高度"不能写成"同一水平线"
(3)光屏上清晰的像的特点 + 应用缩小；照相机根据图丙物距>像距→缩小实像→照相机
(4)根据成像规律判断焦距范围10cm < f < 15cm需根据物距和像距关系推算：u>2f且f

创新要素：以水晶球看远处建筑物引入，激发兴趣。第(4)问要求根据成像规律反推焦距范围，考查逆向思维。

Q20 · 滑动摩擦力的大小与哪些因素有关（力学 · 探究性实验 · ~6分）

实验目的：探究滑动摩擦力的大小与压力、接触面粗糙程度、接触面积的关系

核心器材：弹簧测力计、木块（完全相同）×2、毛巾、细线

实验方法：控制变量法 + 转换法（二力平衡间接测摩擦力）

考查能力点：

子问考查内容答案易错点
(1)拉动方式 + 测量原理匀速直线；二力平衡必须"匀速直线"四个字，不能只写"匀速"
(2)由3、4次实验得出结论压力越大（滑动摩擦力越大）需明确"接触面粗糙程度一定时"这个前提
(3)第3次示数0.25N，用更大力拉，摩擦力变化不变（0.25N）滑动摩擦力与拉力大小无关，只与压力和粗糙程度有关
(4)第5次两木块细线固定一起→面积关系 + 线拉力无关；0.25N接触面积加倍但摩擦力不变→无关。细线拉力=右木块所受摩擦力

创新要素：第(4)问用细线连接两木块的设计巧妙——既验证了"摩擦力与接触面积无关"，又考查了对细线拉力的分析（整体法+隔离法）。

Q21 · 伏安法测小灯泡电阻（电学 · 测量型实验 · ~6分）

实验目的：测量额定电压为2.5V的小灯泡的电阻

核心器材：电源（6V）、小灯泡（额定2.5V）、滑动变阻器、电流表、电压表、开关、导线

实验方法：伏安法（R=U/I）+ 图像法

考查能力点：

子问考查内容答案易错点
(1)电路连接纠错：闭合开关后电流表无示数电流表正负接线柱接反（或导线连接错误），改正后电流表串联在电路中需在图上标"×"并画正确导线
(2)故障排查：灯不亮，电压表无示数，电流表有示数小灯泡短路"电压表无示数+电流表有示数"→被测元件短路
(3)电压表示数读数 + 滑片移动方向读数约1.2V（图乙）；向右移动（增大灯泡电压到2.5V）需判断滑片移动使电阻减小→灯泡分压增大
(4)①滑动变阻器规格选择B（"50Ω 0.5A"）需根据I-U图像最大电流和电源电压计算所需最大阻值
(4)②能否探究电流与电压的关系 + 原因不能；灯泡电阻随温度变化而变化，不是定值电阻探究I与U关系需控制R不变，灯泡不满足

创新要素：第(4)②问从"测电阻"延伸到"能否探究I-U关系"，考查对控制变量法的深层理解。

5.4 压轴题解析

Q9 · 选择压轴（电学综合多选）

题目结构：电源电压不变，滑动变阻器滑片P在A端/B端两种状态，给出U:U'=3:4, P:P'=2:1, R₃=80Ω，R₂消耗功率1.08W。

涉及公式链：U=IR → P=UI=U²/R → 比例法联立方程

设问层次：A.电源电压12V ✅ | B.R₂=20Ω ❌ | C.R₃最大阻值=R₁+R₂ ❌ | D.最小功率37.2W ✅

分步得分策略：先由比例关系列方程求电源电压→再逐项验证。多选题策略：只选最确定的AD，漏选得1分。

Q15 · 填空压轴（浮力方程组）

题目结构：小船漂浮，A放船中/挂船底，B替换A，给出m_B=20g, ρ_A=3ρ_水，排水体积差20cm³和23cm³。

涉及公式链：F浮=G（漂浮）→ F浮=ρ_水gV排 → 列方程组求m_A和ρ_A

答案：m_A=30g, ρ_A=1.5×10³ kg/m³（即3ρ_水=3×10³→ρ_A=3×500=1500? [OCR答案：30g, 1.5×10³]）

区分度：极高。需要对漂浮/悬挂两种情境分别列浮力方程，再联立求解。填空题中罕见的高难度。

Q22 · 力学综合（洒水车）

公式链（按解题顺序）：

m总 = m车 + m水 = 6.7×10³ + 11×10³ = 17.7×10³ kg
→ G = mg = 17.7×10⁴ N
→ p = F/S = G/(6×0.05) = 5.9×10⁵ Pa  【第1问·3分】
→ p水 = ρgh = 1×10³×10×1.6 = 1.6×10⁴ Pa
→ F = pS = 1.6×10⁴×7 = 1.12×10⁵ N  【第2问·3分】
→ W = Pt = 160×10³×5×60 = 4.8×10⁷ J  【第3问·2分】

Q23 · 电学综合（电水壶）

公式链（按解题顺序）：

R₁ = U²/P加热 = 220²/2200 = 22Ω  【第1问·2分】
→ W = Pt = 2200×5×60 = 6.6×10⁵ J  【第2问·2分】
→ Q吸 = Wη = 6.6×10⁵×84% = 5.544×10⁵ J
→ Q = cmΔt → m = Q/(cΔt) = 5.544×10⁵/(4.2×10³×66) = 2 kg  【第3问·2分+2分】
