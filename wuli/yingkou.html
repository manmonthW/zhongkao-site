4.2 逐题实验深度分析

Q18 · 探究冰的熔化特点（6分）热学

分析项内容
实验类型探究性实验
实验目的探究冰熔化过程中温度变化的规律
核心器材酒精灯、烧杯、试管（冰块）、温度计、铁架台（铁杆a、铁夹b、铁圈c）
实验方法水浴加热法（均匀加热）+ 控制变量法
考查能力点
  • 组装顺序：先调节并固定c（铁圈）的位置——自下而上，保证酒精灯外焰加热
  • 读数能力：某时刻温度计示数为-2℃（零下读数）
  • 图像分析：第6min时烧杯内物体处于固液共存态；试管中冰从第10min开始熔化（烧杯中冰先熔化完，试管中冰后熔化）
  • 熔化条件：达到熔点 + 持续吸热两个条件同时满足
  • 应用解释：0℃冰块保鲜比0℃水更好——冰熔化过程中需要吸收热量，温度不变但持续吸热，制冷效果更持久
答案要点(1)c (2)-2 (3)固液共存态；10 (4)持续吸热 (5)冰熔化过程中需要吸收热量
易错点铁圈c与铁夹b混淆；零下温度读数方向搞反；"第10min开始熔化"需结合烧杯与试管的温差分析

Q19 · 探究平面镜成像特点（6分）光学

分析项内容
实验类型探究性实验
实验目的探究平面镜成像的特点（像与物的大小、距离关系）
核心器材薄玻璃板、两支外形相同的蜡烛A和B、白纸、刻度尺
实验方法等效替代法（用未点燃蜡烛B替代像来确定像的位置和大小）
考查能力点
  • 环境选择：在较暗的环境中进行实验——便于观察烛焰的像
  • 器材选择：换用更薄的玻璃板——减小"重影"（前后表面各成一个像）
  • 等效替代：蜡烛B与A的像完全重合→像与物大小相等
  • 位置标记：在a₃处标记像的位置（a₁是蜡烛A位置，a₃是玻璃板后方对应位置）
  • 数据分析：物和像的连线与镜面垂直
  • 虚像本质：玻璃板背面粘贴不透光黑纸后，能看到像——平面镜成虚像，像由反射光线的反向延长线会聚而成，不需要光线穿过玻璃板
答案要点(1)较暗 (2)薄 (3)相等；a₃ (4)垂直 (5)能
易错点a₂和a₃位置混淆；第(5)问"能"——很多学生误选"不能"，忘记虚像是反射光线延长线形成

Q20 · 测量碗的密度——漂浮法（6分）力学

分析项内容
实验类型测量型实验（创新方法）
实验目的不用天平和量筒，利用漂浮法测量碗的密度
核心器材陶瓷碗、底面为正方形的透明水槽、刻度尺、足量水
实验方法漂浮法：漂浮时F浮=G碗 → 浸没时V排=V碗 → 联立求密度
考查能力点
  • 步骤设计：(1)注水测h₁ → 碗漂浮测h₂ → (2)将碗按压入水中使其完全浸没测h₃
  • 浮力分析：漂浮时F浮=G碗=ρ水gS(h₂-h₁)，其中S为水槽底面积
  • 密度推导：V碗=S(h₃-h₁)，ρ碗=m/V=ρ水(h₂-h₁)/(h₃-h₁)
  • 误差分析：步骤(2)若有水溅出→h₃偏小→V碗偏小→密度偏大
  • 拓展测量：要计算碗的质量，还需测量容器底面的边长
答案要点(1)略 (2)将碗按压入水中使其完全浸没 (3)ρ水(h₂-h₁)/(h₃-h₁) (4)变小；变大 (5)容器底面的边长
易错点密度表达式推导中h₁/h₂/h₃的对应关系搞混；误差分析方向判断错误
创新要素⭐ 不用天平和量筒测密度——漂浮法，仅用水槽+刻度尺+水，体现"多种方法测密度"的创新思维

Q21 · 探究电流与电压和电阻的关系（6分）电学

分析项内容
实验类型探究性实验
实验目的探究电流与电压的关系（R不变）；探究电流与电阻的关系（U不变）
核心器材电源(6V)、电流表、电压表、滑动变阻器Rp、定值电阻(10Ω/15Ω/20Ω/30Ω)、开关、导线
实验方法控制变量法
考查能力点
  • 电路纠错：找出一根连接错误的导线并改正（电压表应并联在定值电阻两端）
  • 操作规范：闭合开关前滑片移到最左端（最大阻值端，保护电路）
  • 数据分析：导体电阻一定时，通过导体的电流与电压成正比
  • 读数能力：10Ω接入时电流表示数为0.2A（图乙读数）
  • 控制变量：保持电压表示数为2V不变（U=IR=0.2×10=2V）
  • 变阻器计算：最大阻值不得小于60Ω（当R=30Ω时，U_R=2V，U_Rp=6-2=4V，I=2/30，Rp=4/(2/30)=60Ω）

5.1 命题特色与创新点

① Q6 安全带摆锤装置——惯性深层应用

以汽车安全带控制装置为载体，需判断紧急刹车时摆锤摆动方向（向东紧急刹车→摆锤因惯性向东摆起→锁定安全带）。不是简单的"惯性是什么"，而是"惯性在复杂机械装置中如何起作用"，区分度极高。

② Q9 智能安防电路——光敏电阻+电磁继电器+弹簧控制

控制电路（光敏电阻R₁+定值电阻R₂+电磁铁）与工作电路（灯泡L+滑动变阻器R₃+报警器）联动。需分析白天/夜晚两种状态下的电路行为，并计算滑动变阻器消耗电能W=Pt。涉及光敏电阻特性、电磁继电器工作原理、弹簧固定点调节等多个知识点，是全卷最复杂的选择题。

③ Q20 碗的密度——漂浮法（不用天平和量筒）

仅用水槽+刻度尺+水测量碗的密度，需要学生自主设计"漂浮→浸没"两步操作，推导密度表达式ρ碗=ρ水(h₂-h₁)/(h₃-h₁)。这是"多种方法测密度"的典型创新题，考查实验设计能力和公式推导能力。

④ Q22 斜面模型对比——两种方案的力学综合分析

盘山公路(A)与直路(B)两种方案，高度相同、粗糙程度相同但倾斜程度不同。需计算有用功、效率、摩擦力，并综合对比选择方案。第(4)问"选择哪种方案并分析优点"是开放性分析题，考查学生的综合判断能力。

⑤ Q24 中国电力发展史——最宏大的STEM综合题

从风力发电（流体压强）→特高压输电（减小电流/减少热损）→巡检机器人（W=Fs/能量转化/效率）→压缩空气储能（内能），跨越完整电力产业链。阅读量大、知识点多、计算复杂，是全卷最具综合性和时代感的题目。

5.4 压轴题解析

Q6 选择压轴（惯性+安全带）

结构：安全带摆锤装置，静止/匀速时摆锤竖直→安全带可拉动；紧急刹车时摆锤摆起→锁定安全带。

关键推理：

  • 摆锤摆起如图b所示→摆锤向右摆
  • 紧急刹车时车减速，摆锤因惯性保持原速→摆锤相对车向前摆
  • 摆锤向右=向前→车向右行驶→向东紧急刹车

答案：C（向东紧急刹车）

Q9 选择压轴（智能安防电路）

结构：控制电路（光敏R₁+R₂+电磁铁）+ 工作电路（12V电源+灯泡L"6V 3W"+R₃+报警器）。

关键分析：

  • A错：光敏电阻阻值随光照减弱而增大
  • B错：R₂断路→控制电路断路→电磁铁无磁性→开关断开→灯泡不亮
  • C对：弹簧固定点右移→弹簧更容易被吸合→所需电磁力更小→R₁阻值更大时即可吸合→天刚黑时灯就亮
  • D对：灯泡正常发光U_L=6V，I_L=P/U=0.5A，U_R₃=12-6=6V，P_R₃=U_R₃×I=6×0.5=3W，W=Pt=3×600=1800J ✅

Q15 填空压轴（浮力+绳子+压强）

结构：容器底面积100cm²，正方体物块(0.05kg, 边长5cm)，绳长2cm，绳子拉力0.5N。

公式链：

G = mg = 0.05×10 = 0.5N
V物 = 5³ = 125cm³ = 1.25×10⁻⁴m³
物块完全浸没：F浮 = ρ水gV = 1000×10×1.25×10⁻⁴ = 1.25N
F浮 = G + F绳 → 1.25 = 0.5 + 0.5 ✓（验证浸没）
水深 = 绳长+边长 = 2+5 = 7cm = 0.07m
p = ρ水gh = 1000×10×0.07 = 700Pa [OCR待验证：答案给600Pa，需核实水深]
物块下落至底：F浮=0→需抽水使水面降至物块顶面
抽水质量 = ρ水×ΔV = 0.35kg

注：答案给出p=600Pa，可能水深计算需考虑容器底到绳子固定点的具体位置关系，以标准答案600Pa为准。
