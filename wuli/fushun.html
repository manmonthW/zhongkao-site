4.2 逐题实验深度分析

Q18 · 冰熔化温度变化规律（5分）热学

分析项内容
实验类型探究性实验
实验目的探究冰熔化时温度的变化规律
核心器材酒精灯、烧杯（水浴）、试管（装冰）、温度计、铁架台、石棉网、秒表
实验方法水浴法加热（控制加热均匀）+ 记录温度-时间数据
考查能力点
  • 水浴法目的：便于控制温度并使冰受热均匀
  • 现象观察：试管中出现液体（水）后，说明冰已开始熔化
  • 图像分析：BC段温度不变→冰是晶体；该段物质处于固液共存态
  • 熔化条件：达到熔点，继续（不断）吸热
答案要点(1)便于控制温度并受热均匀 (2)液体（水）；BC；固液共存 (3)达到熔点、不断吸热
易错点"受热均匀"漏写；固液共存态写成"液态"；熔化条件只写一个（需两个同时满足）

Q19 · 凸透镜成像规律（6分）光学

分析项内容
实验类型探究性实验
实验目的探究凸透镜成像的规律（物距与像的性质关系）
核心器材凸透镜（焦距未知）、光具座、蜡烛、光屏
实验方法控制变量法（改变物距，观察像的性质变化）
考查能力点
  • 焦距测量：平行光聚焦法，焦距f=10.0cm
  • 三心同高：实验前应调节烛焰、透镜、光屏中心在同一高度
  • 成像判断：图(b)位置成倒立缩小的实像；将蜡烛移至某位置→光屏向右移动
  • 近视矫正：放置凹透镜后像变模糊，需将光屏向远离透镜（右）方向移动
  • 遮挡实验：用纸板挡住凸透镜上半部分，光屏上仍成完整的像（亮度变暗）
答案要点(1)10.0 (2)同一高度 (3)缩小；右 (4)远离（右） (5)完整（亮度变暗）
易错点焦距写成"10"而非"10.0"（需估读）；近视镜片是凹透镜（发散光线→像后移）；遮挡后误认为像不完整

Q20 · 密度测量（6分）力学

分析项内容
实验类型测量型实验
实验目的测量小石块密度 + 用电子测力计测盐水密度
核心器材天平（含砝码）、量筒、小石块、细线、电子测力计、小石球、盐水、烧杯
实验方法天平+量筒法（石块密度）+ 浮力法（盐水密度）
考查能力点
  • 天平调节：游码归零刻度线，平衡螺母向右调
  • 天平读数：砝码+游码=27.4g
  • 量筒读数：水面从某刻度升至某刻度，体积差=10cm³
  • 密度计算：ρ=m/V=27.4g/10cm³=2.74g/cm³（即2.74×10³ kg/m³）
  • 浮力法测盐水密度：空气中示数F₁→盐水中示数F₂→水中示数F₃
  • 表达式推导：ρ盐水=F₁-F₂/(F₁-F₃) × ρ水
答案要点(1)零刻度线；右 (2)27.4 (3)10；2.74×10³ (4)(F₁-F₂)ρ水/(F₁-F₃)
易错点天平读数忘加游码；量筒读数俯视/仰视误差；盐水密度表达式分子分母搞反
创新要素⭐ 引入电子测力计+浮力法测盐水密度，非传统天平+量筒法，考查灵活运用浮力知识

Q21 · 探究电流与电压和电阻的关系（7分）电学

分析项内容
实验类型探究性实验
实验目的探究电流与电压、电阻的关系（欧姆定律验证）
核心器材电源（6V）、电流表（0~0.6A）、电压表（0~3V）、滑动变阻器（30Ω 1A）、定值电阻（5Ω/10Ω/15Ω/20Ω）、开关、导线
实验方法控制变量法（先控制R不变探究I与U关系，再控制U不变探究I与R关系）
考查能力点
  • 补连电路：用笔画线代替导线将实物电路连接完整（导线不交叉）
  • 滑片方向：闭合开关前滑片移到A端（最大阻值端，保护电路）
  • 电流表读数：电压表2.0V时，电流表示数为0.4A
  • 数据甄别：老师认为第1次数据是拼凑的（不符合正比关系）
  • 结论：电阻一定时，电流与电压成正比
  • 故障排查：换10Ω电阻后两表无示数→滑动变阻器断路
  • 控制电压：用0~3V电压表+30Ω变阻器+20Ω最大电阻，控制电压不低于2.4V
答案要点(1)补连电路 (2)A (3)0.4；1 (4)正 (5)断路 (6)2.4
易错点滑片方向A/B判断错误；数据甄别需验证I=U/R是否成立；控制电压计算需考虑变阻器最大分压

Q9 选择压轴（电学多选）

关键推导：

  • A：灯泡额定功率2.5W → 需从I-U图读取额定电压和电流验证

Q15 填空压轴（浮力+密度）

结构：正方体P（边长10cm）+ 物体Q（体积300cm³）→ P载Q漂浮 → 取下Q投入水中 → 求水面变化和Q的密度。

公式链：F浮=ρ水gV排 → p=ρ水gh → 漂浮条件F浮=G总

关键计算：

  • P下表面压强800Pa → h=p/(ρg)=0.08m=8cm → V排=S×h=100×8=800cm³
  • P体积=1000cm³，浸入8cm → P未完全浸没
  • 取下Q后：需建立方程组求解水面变化和Q的密度
  • 答案：水面下降1cm；Q的密度0.8×10³ kg/m³
