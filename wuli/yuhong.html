4.2 逐题实验深度分析

Q18 · 水和盐水沸腾实验（5分）热学

分析项内容
实验类型探究性实验（对比实验）
实验目的探究水和盐水在沸腾前后温度变化的特点
核心器材酒精灯、烧杯×2、温度计×2、铁架台、石棉网
实验方法控制变量法（相同质量、相同加热条件）+ 对比法
考查能力点
  • 操作规范：按自下而上顺序组装器材（先酒精灯→再铁圈→再烧杯→最后温度计）
  • 现象观察：3min时两烧杯现象不同，判断盐水已沸腾（盐水沸点低于水在该条件下的表现/盐水先达到沸腾状态）
  • 图像分析：沸腾时温度不变（温度-时间图像水平段）
  • 对比结论：用盐水煮面条更容易煮熟，因为其他条件相同时，盐水升温比水快，且沸点比水高
答案要点(1)自下而上 (2)盐水 (3)不变；盐水；其他条件相同时，盐水升温比水快，且沸点比水高
易错点组装顺序写反（自上而下）；混淆"谁先沸腾"与"谁沸点高"

Q19 · 伏安法测小灯泡电阻（6分）电学

分析项内容
实验类型测量型实验
实验目的测量额定电压为2.1V的小灯泡正常发光时的电阻
核心器材电源（3V）、小灯泡（额定2.1V）、电流表、电压表、滑动变阻器、开关、导线
实验方法伏安法（R=U/I）
考查能力点
  • 电路连接：补全实物电路图（导线不交叉）
  • 操作规范：闭合开关前滑片移至B端（最大阻值端，保护电路）
  • 故障排查：灯不亮、两表无示数→滑动变阻器断路
  • 读数能力：电压表示数为2.1V时判断正常发光，电流表读数
  • 深层理解：灯变暗→电阻减小→因为灯丝温度发生改变（电阻随温度变化）
答案要点(1)补全电路 (2)B；断 (3)电压表示数为2.1V (4)温度
易错点故障分析混淆断路/短路；忘记"温度影响电阻"这一核心结论

分析项内容
实验类型探究性实验
实验目的探究平面镜成像的特点（像与物的大小、距离关系）

分析项内容
实验类型探究性实验
实验目的探究液体压强与深度、方向、液体密度的关系

维度五 · 命题DNA：趋势解读

5.1 命题特色与创新点

① Q9 电学压轴多选：双开关+滑动变阻器+I-U图像

两次实验分别闭合不同开关，结合I-U图像综合分析额定功率、电阻值、最大功率。考查学生从图像提取信息并进行多步计算的能力，区分度极高。

② Q15 填空压轴：水位报警器（浮力+压强+浮沉条件）

以压力传感器+浮筒为载体，需综合运用F浮=ρ液gV排、F=pS、浮沉条件，并考虑叠放物体后水位变化。计算量大，是填空题的"隐形压轴"。

③ Q20 平面镜实验含"临摹器"应用拓展

在传统平面镜成像实验基础上，增加"交流"环节——利用玻璃板制作绘画临摹器，需要计算玻璃板角度（80°+50°=130°？实际需补角关系），并判断观察方向。体现"从实验到应用"的STEM思维。

④ Q21 液体压强实验含装置改进

用透明玻璃管替代橡皮膜探头，消除形变误差。这种"发现问题→猜想→改进验证"的思路是新课标重点强调的科学探究能力。

⑤ Q24 STEM综合：垃圾减量化处理（绿色环保主题）

三个任务层层递进：了解手动压实器→设计电动压缩系统→升级自动控制系统。融合力学（杠杆）、电学（电动机、传感器）、工程设计、环保意识，是全卷最具综合性的题目。

5.4 压轴题解析

Q9 选择压轴（电学多选）

结构：电源电压不变，灯泡额定3V，两次实验分别闭合不同开关，结合I-U图像。

公式链：U=IR → P=UI → 串并联分压/分流

关键推导：

  • 第一次：S₁闭合，滑片从最下端到中点时V₂=1.5V，到最上端灯正常发光(3V)
  • A选项：额定功率P=UI=3×0.25=0.75W ✅
  • C选项：R₀=12Ω，需从图像验证 ✅

得分策略：多选题宁可漏选得1分，不要错选得0分。确定A和C后果断提交。

Q15 填空压轴（浮力+压强）

结构：水位报警器，浮筒A（底面积40cm²，高25cm），传感器压力2N触发报警。

公式链：F浮=ρ液gV排 → F传感器=F浮-G → 叠放后水位变化

关键计算：

  • 水面距顶部5cm时报警→浮筒排开水的体积→F浮=G+2N→G=6N
  • 叠放B后：总重增加2N→需多排开水→水位降低5cm

Q22 力学综合（塔吊）

公式链：

G = mg = 1500×10 = 15000N
p = F/S = G/S = 15000/3 = 5000Pa
W = Fs = Gh = 15000×30 = 450000J

得分策略：三问独立，逐问得分。第一问G=mg必拿分。

Q23 电学综合（饮水机）

公式链：

U乙 = IR乙 = 0.4×306 = 122.4V
→ 电源电压（需结合电路分析）
P加热 = 1100W → I加热 = P/U
Q = cmΔt = W = Pt = 1100×420 = 462000J
Δt = Q/(cm) = 462000/(4200×10) = 11°C

得分策略：第一问U=IR直接算，必拿分。第三问注意单位换算（7min=420s）。
