4.2 逐题实验深度分析

Q18 · 液体压强探究 + 滑动摩擦力探究（6分）力学 双实验合题

实验类型：探究性实验 ×2

实验(1) 液体压强：

  • 核心器材：U形管压强计、烧杯、水、盐水
  • 实验方法：控制变量法 + 转换法（U形管液面高度差→压强大小）
  • 考查能力点：
    • 操作规范：U形管两液面不等高时，需将橡皮管取下重新安装（排气校零）
    • 控制变量：比较乙和丙→同种液体中，深度越深压强越大
    • 综合判断：图戊中a/b/c/d/e五点压强最大的是e点（最深处）
  • 答案要点：①将橡皮管取下重新安装 ②深度 ③e

实验(2) 滑动摩擦力：

  • 核心器材：弹簧测力计、木块、木板（正反面粗糙度不同）、钩码
  • 实验方法：控制变量法
  • 考查能力点：
    • 操作规范：木板固定，拉动木块做匀速直线运动
    • 控制变量：比较a和d→接触面粗糙程度影响摩擦力
    • 应用拓展：两纸箱不同方式推动→F₁=F₂（接触面和压力相同，摩擦力相同）
  • 答案要点：④匀速直线运动 ⑤a和d ⑥F₁=F₂

易错点：U形管校零操作表述不准确；匀速直线运动漏写"匀速"；纸箱推力比较忽略接触面积不影响摩擦力

Q19 · 果糖密度测量（5分）力学 跨学科（奶茶店品控）

实验类型：测量型实验 + 方案设计

实验目的：测量不同浓度果糖溶液的密度，确定果糖浓度

核心器材：天平、量筒 / 天平、烧杯、水

实验方法：ρ=m/V（常规法）+ 等量替代法（不用量筒方案）

考查能力点：

  • 数据分析：果糖浓度越高，密度越大
  • 查表应用：100mL样品质量105g → ρ=1.05g/cm³ → 查表得浓度约10%
  • 方案设计（核心难点）：不用量筒，只用天平+烧杯+水测密度
    • ①测空烧杯质量m₀
    • ②装适量水，标记液面，测总质量m₁
    • ③倒出水，擦干烧杯，倒入果糖溶液至标记处，测总质量m₂
    • ④ρ果糖 = ρ水(m₂-m₀)/(m₁-m₀)
  • 误差分析：夏季温度升高→体积膨胀→测出密度偏小

答案要点：(1)大 (2)10% (3)③倒入果糖溶液至标记处 ④ρ=ρ水(m₂-m₀)/(m₁-m₀) (4)小

易错点：密度表达式分子分母搞反；忘记"擦干烧杯"步骤；误差方向判断反

创新要素：⭐ 跨学科情境（奶茶店品控）+ 替代方案设计（不用量筒测密度）

Q20 · 凸透镜成像规律（6分）光学

实验类型：探究性实验

实验目的：探究凸透镜成像的规律（f=10.0cm）

核心器材：凸透镜(f=10cm)、蜡烛、光屏、光具座

实验方法：控制变量法（改变物距观察像距和像的特征）

考查能力点：

  • 操作规范：调整烛焰、凸透镜、光屏中心同一高度→使像成在光屏中央
  • 判断标准：移动光屏直到出现清晰的像才记录数据
  • 规律总结：物距>焦距时，物距减小→像距增大
  • 应用拓展：放大镜对应u<f的情况（表中某次实验）
  • 进阶探究：探究像大小与焦距关系→换f=15cm凸透镜→物距相等→像大小不等→说明有关

答案要点：(1)光屏中央；清晰的像 (2)增大 (3)第X次(u<f) (4)相等；不等

易错点："清晰的像"误选"光斑"；物距与像距变化关系搞反；探究焦距影响时物距应"相等"而非"不等"

Q21 · 电流与电压、电阻的关系（7分）电学

实验类型：探究性实验

实验目的：探究电流与电压、电阻的关系（电源3V，变阻器"20Ω 2A"）

核心器材：电源(3V)、电流表、电压表、开关、5Ω/10Ω/20Ω/30Ω定值电阻、滑动变阻器(20Ω 2A)、导线

实验方法：控制变量法

考查能力点：

  • 电路纠错：找出一根连接错误的导线，打×并重新画线（电压表应并联在定值电阻两端）
  • 故障诊断：电流表无偏转+电压表有示数→定值电阻断路（选C：检查定值电阻接线柱是否接触良好）
  • 读数能力：第5次电压表示数读数（0-3V量程）
  • 结论归纳：电阻一定时，电流与电压成正比
  • 控制变量：换电阻后移动滑片使电压表示数为2.0V（控制电压不变）
  • 变阻器作用：保护电路 + 控制定值电阻两端电压不变

答案要点：(1)纠正导线连接 (2)C (3)读数值 (4)正 (5)电压表；2.0V；保护电路和控制定值电阻两端电压不变

易错点：故障诊断混淆断路/短路（电流表无示数+电压表有示数=被测元件断路）；变阻器作用只写"保护电路"漏写"控制电压不变"

5.4 压轴题解析

Q9 选择压轴（电学多选）

结构：电源电压恒定，电流表0-0.6A，电压表0-15V。第一次闭合S₁S₂滑片从a到b；第二次闭合S₁S₃移动滑片。I-U图像两条线。

公式链：U=IR → P=UI → 串联分压

关键判断：A.R₀=20Ω B.灯泡参数"3.5V 0.4A" C.电阻比5:3 D.变阻器最小阻值7.5Ω

得分策略：多选题宁可漏选得1分。先确定最有把握的选项。

Q15 填空压轴（弹簧+浮力+密度）

结构：弹簧原长10cm，压缩至6cm（ΔL=4cm），k=1N/cm → F弹=4N=G木块。木块边长10cm，半浸没时弹簧自然→F浮=G→ρ液×g×V排=G。

公式链：

F弹 = kΔx = 1×4 = 4N = G
m = G/g = 0.4kg
ρ木 = m/V = 0.4/0.001 = 400kg/m³
半浸没: F浮 = ρ液g(V/2) = G = 4N
ρ液 = 2G/(gV) = 800kg/m³

再放B：需根据力的平衡和液面变化计算G_B。
