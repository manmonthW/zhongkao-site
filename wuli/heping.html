4.2 逐题实验深度分析

Q18 · 探究水沸腾前后温度变化的特点（6分·热学）

项目内容
实验类型探究性实验
实验目的探究水沸腾前后温度变化的特点
核心器材铁架台、酒精灯、烧杯、温度计、纸板、石棉网
实验方法观察法、记录法

考查能力点与答案：

小题考查能力答案
(1)组装顺序（自下而上）先观察酒精灯外焰的高度，再确定铁圈A的高度；温度计玻璃泡完全浸没在水中
(2)物态变化辨析（白气成因）"白气"是烧杯中冒出的水蒸气液化形成的
(3)沸腾现象理解气泡内主要是水蒸气；继续加热，水的温度不变

易错点：①"白气"容易误选"空气中"的水蒸气；②气泡内容易误选"水中溶解的气体"；③组装顺序必须"自下而上"，先定酒精灯外焰高度。

Q19 · 盐水密度测量 + 自制密度计设计（7分·力学）——本卷最大亮点

项目内容
实验类型测量型实验 + 设计型实验
实验目的测量盐水密度；利用漂浮原理制作密度计
核心器材托盘天平、量筒、烧杯、盐水；金属丝、刻度尺、空心圆柱直杆、已知密度液体
实验方法转换法（质量÷体积→密度）、等效替代法（漂浮条件→密度计）

考查能力点与答案：

小题考查能力答案
(1)调零天平调节（平衡螺母方向）向右调节
(1)②读数天平读数m₁ = 78 g
(1)计算密度计算 ρ=m/Vρ = 1.1×10³ kg/m³
(1)误差误差分析（残余盐水）没有影响（先测总质量再倒出，残余不影响质量差）
(2)①漂浮条件判断浮力等于重力
(2)画图密度计刻度标注液面位置在0.8与0.9之间靠近0.8的位置
(2)改进实验改进分析金属丝置于杆内，重心下移，浸入深度增大，密度值标注上移

易错点：①误差分析：此实验先测总质量再倒出，残余盐水使V偏小但m也偏小，实际对密度无影响（特殊设计）；②密度计刻度：密度越大浸入越浅，0.85在0.8和0.9之间靠近0.8处；③金属丝内置后重心下移，浸入更深，刻度上移。

Q20 · 凸透镜成像规律·近视眼矫正原理（5分·光学）

项目内容
实验类型探究性实验
实验目的了解凸透镜成像规律及近视眼矫正原理
核心器材光具座、F型发光二极管光源、凸透镜、光屏、凹透镜
实验方法控制变量法（固定透镜和光屏，移动光源）

考查能力点与答案：

小题考查能力答案
(1)实验操作规范使F型光源、凸透镜和光屏的中心在同一高度
(2)成像成像特点判断光屏上得到缩小的像；手指触碰凸透镜→C.光屏上发光物体的像变暗
(3)近视眼模拟向远离透镜（向右）移动光屏
(4)近视眼矫正在发光物体和凸透镜之间放置一个凹透镜

易错点：①手指遮挡凸透镜部分，像不会缺少部分，只会变暗（光线减少）；②近视眼成像在视网膜前方，需用凹透镜发散光线使像后移。

Q21 · 探究电阻一定时电流与电压的关系（6分·电学）

项目内容
实验类型探究性实验
实验目的探究电阻一定时，通过导体的电流与导体两端电压的关系

实验方法控制变量法（控制电阻不变，改变电压）

考查能力点与答案：

小题考查能力答案
(1)滑动变阻器的作用使用滑动变阻器可以改变定值电阻两端的电压（或方便多次测量）

(4)电流表读数电压表0.3V时，电流表示数为0.08A

5.4 压轴题解析

Q6（选择压轴）· 超声波测速计算

题目结构：测速仪两次发射超声波，根据时间差计算车速。

第一次距离：s₁ = 340×0.4/2 = 68m
第二次距离：s₂ = 340×0.2/2 = 34m
汽车行驶距离：Δs = s₁ - s₂ = 34m
汽车行驶时间：Δt = 1.8 - 0.4/2 + 0.2/2 = 1.8s（近似）
实际：Δt = 1.8 - 0.2 + 0.2/2 ... → v ≈ 18.9m/s → 答案B

区分度：极高。需要画出时间轴示意图，理清两次发射和接收的时间关系，是选择题中最难的一道。

Q9（多选压轴）· 电功率综合电路

题目结构：灯泡"10V 5W" + 滑动变阻器R₁（最大电流1A）+ 两个开关切换 + U-I图像分析。

涉及公式链：U=IR → P=UI → P=I²R → P=U²/R，结合U-I图像读取数据。

答案AD：A.电源电压12V ✅；D.滑动变阻器阻值变化范围4~50Ω ✅。B和C需要仔细计算验证。

区分度：极高。多选题错选0分，需要逐一验证每个选项，建议不确定的选项宁可不选（漏选得1分）。

Q22（力学综合）· 卷扬机+动滑轮

(1) p = F/S = G/S = 800N / 0.2m² = 4000Pa
(2) F = (G物+G轮)/2 = (800+100)/2 = 450N（忽略绳重和摩擦，2段绳）
(3) W有用 = Gh = 800N × 2m = 1600J

分步得分策略：第(1)问送分（p=F/S直接代入）；第(2)问需判断绳子段数n=2；第(3)问注意有用功只算物体重力做的功。

Q23（电学综合）· 家庭用电

(1) 用电量 = 月末 - 月初 电能表读数
(2) I = P/U = 2000W / 220V ≈ 9.09A
(3) Q = W = Pt = 1100W × 100s = 1.1×10⁵J
(4) 建议：不同时使用大功率用电器

分步得分策略：第(1)(2)问基础送分；第(3)问注意电热水壶额定功率1100W；第(4)问开放性建议，答"不同时使用大功率用电器"即可。

6.3 公式链速查

Q22 力学公式链

G = mg（重力）
↓
p = F/S = G/S（压强，F=G因为水平面静止）
↓
F拉 = (G物 + G轮) / n（动滑轮，n=绳子段数）
↓
W有用 = Gh（有用功 = 物体重力 × 提升高度）
↓
W总 = Fs = F拉 × ns（总功，s为绳子自由端移动距离）
↓
η = W有用 / W总（机械效率）

Q23 电学公式链

W = 电能表读数差 × 每度电能量（1kW·h = 3.6×10⁶J）
↓
I = P / U（额定电流）
↓
Q = W = Pt = UIt（电热 = 电功，纯电阻电路）
↓
安全用电：总电流 < 保险丝额定电流
