Q18 · 同一直线上二力的合力 + 天平测量（6分）力学

分析项内容
实验类型探究性实验 + 测量型实验（复合题）
实验目的①掌握天平的使用方法 ②探究同一直线上二力合力的规律
核心器材天平（最小砝码5g）、弹簧测力计×3、橡皮筋
实验方法等效替代法（一个力的效果替代两个力的效果）
考查能力点
  • 仪器识别：图甲为测量质量的仪器（天平）
  • 天平操作：放大部分为指针和分度盘；接下来操作：向右调节平衡螺母直至天平在水平位置平衡
  • 等效替代：三次实验中弹簧都从A点拉伸到B点，使力的作用效果相同
  • 数据推理：根据图丙-b推断图丙-a中F₂=2N（同向合力=两力之和）
  • 反向合力：F₃=4N，F₄与F₃同一直线反向，则F₄=2N（反向合力=两力之差，合力等于F₃-F₄或F₄需使合力等于某值）
答案要点(1)质量；分度盘；向右调节平衡螺母 (2)①相同 ②2N ③2N
易错点天平"分度盘"名称写错；反向合力计算方向搞反

Q19 · 凸透镜成像规律——水透镜（6分）光学

分析项内容
实验类型探究性实验
实验目的探究凸透镜成像规律（利用水透镜可变焦距的特点）
核心器材水透镜（注水/抽水改变焦距）、蜡烛、光屏、光具座
实验方法控制变量法 + 观察法
考查能力点
  • 焦距测量：平行光聚焦在光屏上得到最小最亮光斑，焦距=光斑到透镜距离=10cm
  • 操作规范：调节烛焰、水透镜和光屏的中心在同一高度上
  • 实验环境：应在较暗的环境中进行实验
  • 成像规律：图乙位置成倒立、放大的实像（f<u<2f时）
  • 虚像观察：蜡烛距透镜5cm（u<f），应从光屏一侧透过水透镜观察（虚像，同侧）
  • 近视眼矫正："戴上"眼镜后注入适量水（减小焦距）使像再次清晰→戴的是近视眼镜（凹透镜，使光线发散）
答案要点(1)10cm (2)同一高度 (3)暗 (4)放大 (5)光屏 (6)近视
易错点虚像观察方向（从光屏侧看，不是从蜡烛侧看）；近视/远视眼镜混淆
创新要素⭐ 水透镜——通过注水/抽水改变焦距，是创新器材，替代传统固定焦距凸透镜

Q20 · 液体压强探究 + 盐水密度测量（6分）力学

分析项内容
实验类型探究性实验 + 测量型实验
实验目的①探究液体压强与哪些因素有关 ②测量盐水密度
核心器材U形管压强计（加装三通接头）、烧杯、水、盐水、玻璃管、橡皮膜、刻度尺
实验方法控制变量法 + 转换法（U形管液面高度差反映压强大小）
考查能力点
  • 气密性检查：阀门K打开，确保U形管两侧液面相平（与大气相通）；轻按橡皮膜，U形管液面差变化明显且稳定→气密性良好
  • 控制变量：比较图乙与图丙→同种液体在同一深度向各个方向的压强相等
  • 灵敏度改进：深度较浅时高度差不明显→换密度更小的液体（如酒精）
  • 密度测量设计：玻璃管+橡皮膜装水→浸入盐水→橡皮膜恢复平齐→p水=p盐水→ρ水gh₁=ρ盐水gh₂→ρ盐水=ρ水h₁/h₂
  • 误差分析：橡皮膜恢复平齐时实际仍有微小形变→测出的盐水密度将偏大
答案要点(1)U形管两侧液面相平；良好 (2)相等 (3)小 (4)ρ水h₁/h₂；偏大
易错点"更小"易误写为"更大"（换密度小的液体使U形管更灵敏）；密度表达式分子分母搞反
创新要素⭐ 三通接头改进装置 + 玻璃管+橡皮膜测盐水密度（创新测量方法）

Q21 · 电流与电压的关系（6分）电学

分析项内容
实验类型探究性实验 + 测量型实验
实验目的①探究电流与电压的关系 ②测量滑动变阻器Rx的最大阻值
核心器材电源（3V）、电流表（0-0.6A）、电压表（0-3V）、滑动变阻器、定值电阻、开关、导线
实验方法控制变量法（定值电阻不变，改变电压观察电流）
考查能力点
  • 电路连接：补全实物电路（滑片P向左移动时电流表示数变大→滑片左移阻值减小→接法确定）
  • 故障排查：V表和A表均无示数→电路断路；V接ab=3V，V接ac=0V，V接bc=3V→定值电阻断路（bc段有完整电压降）
  • 数据处理：根据表格数据在坐标纸上作I-U关系图像（过原点的直线）
  • 实验结论：电阻一定时，通过导体的电流与导体两端的电压成正比
  • 拓展测量：测Rx最大阻值——①滑片移至最左端读I₁ ②将滑片移至最右端读I₂ ③Rx=R₀(I₁-I₂)/I₂（或I₁R₀/I₂-R₀）
答案要点(1)补全电路 (2)定值电阻 (3)作图 (4)电阻一定时，电流与电压成正比 (5)将滑片移至最右端；R₀(I₁-I₂)/I₂
易错点故障排查逻辑链（需逐段分析电压分布）；Rx表达式推导（需用等式U=I₁R₀=I₂(R₀+Rx)）

5.4 压轴题解析

Q9 选择压轴（电学多选）

结构：水位监测装置，R₀为定值电阻，R滑竖直放置（最大阻值40Ω），浮子带动滑片。

公式链：U=IR → P=UI → 串联分压

关键推导：

  • 水位升高→浮子上升→滑片上移→R滑接入阻值减小→总电阻减小→I增大→UR₀增大→U表=U-UR₀减小 → A选项✅
  • 从乙图：水位10cm时R=30Ω；从丙图对应点读取U和I→P滑=UI
  • 水位25cm（警戒）时R=10Ω→代入计算U表和总功率

得分策略：多选题宁可漏选得1分。A选项（定性分析）最易确认，优先锁定。

Q15 填空压轴（浮沉子）

结构：大塑料瓶+小玻璃瓶（圆柱形，S=2cm²，h=8cm），两次挤压。

公式链：F浮=ρ水gV排 → 漂浮：F浮=G → 悬浮：ρ物=ρ水

关键计算：

  • 第一次挤压（漂浮）：h₁=3cm（瓶内外水面差），h₂=7cm（开口到大瓶水面）→小瓶浸入深度=h₂-h₁=4cm？需根据几何关系建立方程
  • 漂浮时：G瓶+G水=F浮=ρ水g·S·h浸
  • 第二次挤压（悬浮）：ρ物=ρ水→总质量=ρ水·V瓶→水增加质量=总质量-瓶质量-原有水质量

答案：小瓶质量=10g；水增加质量=6g

Q22 力学综合（氢气动力汽车，10分）

已知：G=1.5×10⁴N，S=0.1m²，t=5min=300s，s=6×10³m，F牵=1.0×10³N，m氢=0.075kg，q氢=1.4×10⁸J/kg

(1) p = F/S = G/S = 1.5×10⁴/0.1 = 1.5×10⁵Pa
(2) W = Fs = 1.0×10³ × 6×10³ = 6×10⁶J
(3) P = W/t = 6×10⁶/300 = 2×10⁴W
(4) Q放 = mq = 0.075 × 1.4×10⁸ = 1.05×10⁷J
    η = W/Q放 = 6×10⁶/1.05×10⁷ ≈ 57.1%

得分策略：4问独立，逐问得分。前3问直接代入公式，必拿7-8分。第4问注意效率保留一位小数。
