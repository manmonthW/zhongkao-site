# 物理单卷深度分析 Skill（六维分析模型）

> 适用于：辽宁中考物理模拟卷逐卷分析
> 输入：OCR文本 + 答案（如有）
> 输出：单张HTML页面，内嵌CSS，无外部依赖

## 一、分析框架总览

物理不同于数学的纯逻辑推演，物理试卷分析必须体现：
- **实验是灵魂**：30%分值在实验题，必须单独深度剖析
- **公式是骨架**：每道计算题背后是明确的公式链，必须逐题标注
- **五大板块定位**：力学/电学/光学/热学/声学，而非数学的四大领域
- **情境即考点**：物理题的生活/科技情境不是装饰，是考查载体

六个维度：

| 维度 | 名称 | 核心问题 | 物理特色 |
|------|------|----------|----------|
| 一 | 骨架图·结构解剖 | 这张卷子长什么样？ | 五大题型固定结构（选择/填空/作图/实验/综合） |
| 二 | 逐题档案·考点定位 | 每道题考什么？ | 逐题标注：知识板块 + 核心公式 + 物理思想方法 + 难度 |
| 三 | 板块透视·知识地图 | 五大板块怎么分布？ | 力电光热声分值占比 + 教材章节映射 + 核心素养覆盖 |
| 四 | 实验深剖·探究解码 | 实验题怎么出的？ | 四板块覆盖检查 + 实验类型 + 关键能力 + 创新器材/方法 |
| 五 | 命题DNA·趋势解读 | 命题人想考什么？ | 情境化分析 + STEM综合题拆解 + 新课标对标 + 压轴题解析 |
| 六 | 作战地图·行动转化 | 怎么拿分？ | 分数段策略 + 公式链速查 + 易错预警 + 实验操作要点 |

## 二、维度一：骨架图·结构解剖

### 输出内容

## 三、维度二：逐题档案·考点定位

### 这是物理分析的核心维度，与数学最大的区别在于必须标注「核心公式」和「物理思想方法」

### 选择题表格

| 题号 | 分值 | 单/多选 | 考查内容 | 知识板块 | 核心公式/概念 | 物理思想方法 | 难度 | 答案 |
|------|------|---------|----------|----------|---------------|-------------|------|------|

**物理思想方法**包括（与数学不同）：
- 控制变量法（实验设计核心）
- 转换法（不可直接测量→间接测量）
- 等效替代法（合力/等效电路）
- 类比法（水流类比电流）
- 模型法（光线模型/磁感线模型）
- 理想化方法（忽略摩擦/空气阻力）
- 图像法（I-U图/s-t图/温度-时间图）
- 估算法（估测题）

### 填空题表格

| 题号 | 分值 | 考查内容 | 知识板块 | 核心公式 | 答案要点 | 难度 |

特别标注：
- Q15 通常是填空压轴（浮力/压强/密度综合计算），需单独说明解题思路

### 作图题表格

| 题号 | 分值 | 作图类型 | 知识板块 | 评分要点 |

作图类型固定为以下几种：
- 光路图（反射/折射/凸透镜成像）
- 力的示意图（重力/摩擦力/浮力/支持力）
- 力臂标注
- 电路图补全

### 实验题表格（详见维度四单独深剖）

| 题号 | 分值 | 实验名称 | 知识板块 | 实验类型 | 关键能力点 |

### 综合应用题表格

| 题号 | 分值 | 情境 | 知识板块 | 涉及公式链 | 子问数 | 难度梯度 |

**公式链**是物理综合题的核心特征，例如：
- Q22力学：G=mg → p=F/S → W=Fs → P=W/t → η=W有/W总
- Q23电学：U=IR → P=UI → W=Pt → Q=cmΔt → η
- Q24 STEM：概念填空 → 简单计算 → 综合分析

### 维度二末尾总结卡片
- 物理思想方法频次统计
- 公式出现频次排名

## 五、维度四：实验深剖·探究解码

> 这是物理分析区别于所有其他学科的独有维度。实验题占30%分值，是物理的灵魂。

### 5.1 四板块覆盖检查

| 板块 | 是否覆盖 | 题号 | 实验名称 |
|------|----------|------|----------|
| 热学 | ✅/❌ | | |
| 光学 | ✅/❌ | | |
| 力学 | ✅/❌ | | |
| 电学 | ✅/❌ | | |

**铁律**：绝大多数试卷实验题覆盖力/电/光/热四板块。如有缺失，必须标注为「重要偏差」。

### 5.2 逐题实验深度分析

每道实验题单独一个卡片，包含：

**实验名称 + 分值 + 板块**

- **实验类型**：探究性实验 / 测量型实验 / 设计型实验
- **实验目的**：一句话
- **核心器材**：列出关键器材
- **实验方法**：控制变量法 / 等效替代法 / 转换法 等
- **考查能力点**（逐条列出）：
  - 操作规范（组装顺序/调零/调平衡）
  - 读数能力（天平/量筒/弹簧测力计/电流表/电压表）
  - 数据处理（画图像/算均值/分析趋势）
  - 故障排查（断路/短路/接触不良）
  - 误差分析（偏大/偏小及原因）
  - 实验改进/创新拓展
- **答案要点**：逐空列出
- **易错点**：具体标注

### 5.3 实验创新要素

标注本卷实验题中的创新设计：
- 创新器材（水透镜/密度秤/压敏电阻等）
- 创新方法（多种测密度方法/自制仪器等）
- 跨学科拓展（密度计制作/传感器应用等）

### 7.3 公式链速查

按综合题解题顺序排列：

**Q22 力学公式链：**
```
G = mg
↓
p = F/S  或  p = ρgh
↓
W = Fs  或  W有 = Gh
↓
P = W/t  或  P = Fv
↓
η = W有/W总
```

**Q23 电学公式链：**
```
U = IR（欧姆定律）
↓
P = UI = I²R = U²/R
↓
W = Pt = UIt
↓
Q = cmΔt（水吸热）
↓
η = Q吸/W电
```

### 7.4 易错点预警表

| 题号 | 易错点 | 防范措施 |
|------|--------|----------|
| | | |

物理高频易错点类型：
- 单位换算（cm²→m², mL→m³, kW·h→J, mA→A）
- 多选题错选（宁可漏选得1分，不要错选得0分）
- 作图不规范（光线不标箭头/力的作用点错误/虚实线混淆）
- 实验读数（量筒俯视偏大/天平游码读数/电表量程选错）
- 公式变形错误（P=U²/R 用于串联时R不是总电阻）
- 效率公式分子分母搞反

### 7.5 实验操作要点速查

针对本卷涉及的实验，列出操作规范要点：
- 天平使用：先调零→再调平衡→左物右码→读数
- 量筒读数：视线与凹液面最低处相平
- 电路连接：先串后并→开关断开→滑动变阻器最大阻值
- 凸透镜：三心同高（烛焰中心/透镜光心/光屏中心）

## 九、与数学五维模型的关键差异

| 维度 | 数学 | 物理 |
|------|------|------|
| 知识分类 | 四大领域（数与代数/图形与几何/统计与概率/综合与实践） | 五大板块（力学/电学/光学/热学/声学） |
| 思想方法 | 数形结合/转化化归/分类讨论/函数思想 | 控制变量法/转换法/等效替代法/模型法/图像法 |
| 核心素养 | 9项（抽象/运算/几何直观/空间观念/推理/模型/数据/应用/创新） | 4项（物理观念/科学思维/科学探究/科学态度与责任） |
| 独有维度 | 无 | 维度四「实验深剖」（30%分值的实验题需要独立深度分析） |
| 压轴结构 | 几何压轴 + 代数压轴（各1道） | Q9电学多选 + Q15填空 + Q22力学 + Q23电学 + Q24 STEM（5个压轴点） |
| 公式体系 | 较少（面积/勾股/二次函数） | 大量（力学链/电学链/热学链），必须逐题标注公式 |
| 教材定位 | 七上~九下（6个学期） | 八上~九全（3个学期，但内容密度极高） |

## 十、分析流程 Checklist

拿到一套物理模拟卷的OCR文本后，按以下顺序执行：

- [ ] 1. 确认试卷结构（24题/80分？实验/综合分值有无微调？）
- [ ] 2. 逐题标注：考点 + 知识板块 + 核心公式 + 难度 + 答案
- [ ] 3. 统计五大板块分值分布，与11套卷均值对比
- [ ] 4. 检查实验题四板块覆盖（力/电/光/热），标注缺失
- [ ] 5. 深度分析每道实验题（类型/方法/能力点/创新要素）
- [ ] 6. 拆解Q24 STEM综合题（主题/子问/跨学科要素）
- [ ] 7. 分析压轴题（Q9/Q15/Q22/Q23）的公式链和分步策略
- [ ] 8. 标注情境化命题（类型/占比）
- [ ] 9. 制定分数段策略和必拿分清单
- [ ] 10. 整理易错点预警和公式速查
- [ ] 11. 生成HTML页面，检查导航链接
