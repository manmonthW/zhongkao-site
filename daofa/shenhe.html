维度四 · 命题DNA（命题解码）

DNA-1：生态环境法典深度解读（12分）

单一法律12分——六套卷最深度的法治专题

Q19用5个小问系统解剖《生态环境法典》：

  1. 宪法地位(2分)：法典的立法基础和依据→宪法
  2. 立法方法(2分)："适度法典化"→科学立法
  3. 法律温度(2分)：油烟净化/降噪限值→尊重和保障人权
  4. 法治意义(2分)：绿色低碳发展→保护环境基本国策
  5. 践行行动(4分)：做"法典明白人"+"条文行动派"→开放写作

这是对一部新法律的全链条考查：宪法依据→立法方法→立法精神→社会意义→个人行动。

DNA-2：文化自信专题（9分）

Q18整题聚焦中华文化——三个维度
  • 文韵·寄情（4分）：春晚《贺花神》→文化创造力和包容力 + 创造性转化创新性发展
  • 文和·融情（2分）：柏林/墨西哥/肯尼亚春节活动→中国文化对世界影响力
  • 文俗·燃情（3分）："东北超"足球嘉年华→东北特色文化 + 文化自信

"东北超"命题是亮点——将东北体育+民俗+城市文化融为一体，接地气。

DNA-3：开卷命题特征

开卷考试对命题的影响
  • 纯识记题仍有(但翻书可解)：Q8兵役义务/Q9荣誉权/Q10国有经济/Q15和平与发展→开卷可快速翻到
  • 理解应用题增多：Q6行政违法判断/Q13反选匹配/Q14排除法→翻书找不到直接答案
  • 材料提取题增多：Q18(3)从材料中举例说明/Q19(3)概括材料观点→需读懂材料而非背诵
  • 开放写作仍是区分度核心：Q16(4)3分 + Q19(5)4分 = 7分

维度五 · 作战地图（行动转化）

优先级一：开卷翻书策略（节省时间的关键）

开卷≠不需要准备

开卷考试的陷阱是"翻书找答案浪费时间"。正确策略：

  1. 提前做好课本标签：用便利贴标注核心概念页码（宪法/人大/国安/经济/文化/生态）
  2. 识记类快速确认：Q8兵役/Q10国有经济/Q15时代主题→翻书确认即可(每题30秒)
  3. 理解类不翻书：Q6行政违法/Q13反选→翻书找不到直接答案，靠理解判断
  4. 材料分析类不翻书：Q18(3)/Q19(3)→答案在材料中而非课本中

优先级二：法治+生态双线速记（~22分）

本卷两大高频考线

法治线（16分）：

  • 宪法是立法基础和立法依据(Q19①)
  • 全面依法治国→科学立法(Q19②)
  • 尊重和保障人权(Q19③)
  • 全国人大→决定权vs立法权(Q17①)
  • 最高国家权力机关(Q17②)

文化线（9分）：

  • 中华文化→创造力和包容力(Q18①)
  • 创造性转化、创新性发展(Q18②)
  • 文化自信(Q18⑤)
