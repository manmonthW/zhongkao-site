维度四 · 命题DNA（命题解码）

DNA-1：组合选择题"重灾区"

53%组合选择题占比——六套卷中最高

8道组合题(Q2/Q4/Q6/Q8/Q9/Q11/Q12/Q13)全部采用"给3-4个判断项、选正确组合"模式。干扰项主要手法：

  • 绝对化/夸大：Q11"教育是当前一切工作的中心"（经济建设才是）、Q11"有效解决所有发展矛盾"
  • 混淆行为属性：Q4"沉迷网络休闲娱乐"/"随意发表网络言论"均为反面行为
  • 方向倒置：Q6"灵活变通，自我便利为先"与规则意识矛盾、"重视他律，放弃自我约束"逻辑矛盾
  • 概念偷换：Q8"限制公民自由，实现绝对公平"（爱心座不限制自由，且公平非绝对）

维度五 · 作战地图（行动转化）

优先级一：组合选择题排除法专练

53%组合题=本卷胜负手

四大干扰项识别口诀：

  1. "一切/所有/绝对/消除"→一律排除（Q11"解决所有矛盾"/Q8"绝对公平"）
  2. 方向倒置→排除（Q6"放弃自我约束"/Q4"沉迷网络"）
  3. 概念偷换→排除（Q8"限制公民自由"/Q9"制约"非公有制经济）
  4. 因果倒推→排除（Q12"共享发展是最鲜明特色"→应为"改革开放"）

训练方法：每天做5道组合选择题，不看选项先逐项判断对错，再对照答案。

优先级二：九上国情国策速记（~37分 / 52.9%）

必背清单（按本卷考频排序）
  1. 政治制度线：人民当家作主(Q19①) / 全面从严治党(Q19②) / 监察委员会(Q19③) / 依法治国(Q17①)
  2. 经济建设线：非公有制经济·鼓励支持引导(Q9) / 共同富裕(Q12) / 以人民为中心(Q19④)
  3. 民族关系线：中华民族共同体意识(Q17③) / 民族团结进步促进法
  4. 文化自信线：中华文化·物质文化(Q18①) / 革命文化(Q18③) / 自信中国人(Q13)
  5. 科教兴国线：教育是民族振兴基石(Q11)
  6. 一国两制线：一国两制·香港(Q14)
  7. 绿色发展线：生态文明建设·五位一体(Q18⑤)
  8. 国际秩序线：人类命运共同体·合作共赢(Q15) / 中国智慧·中国方案(Q17④)

优先级三：两个开放题写作模板（Q16④ + Q19⑤ = 7分）

Q16(4) 评析同学观点模板（3分）

两个观点可选：
观点A："把梦想融入国家发展"——结合"少年有梦"知识：个人梦想与中国梦相连+把个人理想融入国家发展
观点B："在平凡中闪耀出伟大"——结合"生命的思考"知识：生命的意义在于对社会的贡献+在平凡中创造伟大

万能结构：①表态（该观点正确/我赞同）→ ②联系知识点 → ③结合金城龙材料论证 → ④总结

Q19(5) "青春答卷"写作模板（4分）

三选一：创新强国 / 法治中国 / 美丽中国，50字以上。

示例（选"建设法治中国"）：作为新时代青少年，我将积极学习法律知识，增强法治意识，自觉遵守法律法规，依法行使权利、履行义务。在日常生活中，我将运用法律武器维护自身合法权益，敢于同违法行为作斗争，为建设法治中国贡献青春力量。
