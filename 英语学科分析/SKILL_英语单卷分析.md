# 英语单卷深度分析 Skill（五维分析模型）

> 适用于：辽宁中考英语模拟卷逐卷分析
> 输入：OCR文本 + 答案（如有）
> 输出：单张HTML页面，内嵌CSS，无外部依赖

---

## 一、分析框架总览

英语试卷分析的核心特征（与理科学科的根本差异）：
- **阅读是灵魂**：阅读选择(32分)+阅读还原(8分)+阅读与表达(10分)=50分，占笔试56%
- **写作占22%**：书面表达20分，是单题分值最高的题目
- **听力独立30分**：但听力由各市单独组织（沈阳一般4月考完），模拟卷主要针对笔试
- **无公式无计算**：考查语言理解、词汇运用、语法应用、书面表达能力
- **语法嵌入语篇**：2024年改革后删除传统单选题，语法全部在语篇填空中考查
- **五选四是新题型**：阅读还原直接对标高考，考篇章逻辑

五个维度：

| 维度 | 名称 | 核心问题 | 英语特色 |
|------|------|----------|----------|
| 一 | 骨架图·结构解剖 | 卷子长什么样？ | 听力30+笔试90=120分，阅读占笔试56% |
| 二 | 题型谱·逐题档案 | 每道题考什么？ | 逐篇分析：话题+体裁+设题类型+正确选项逻辑 |
| 三 | 考点标签·知识定位 | 知识怎么分布？ | 语法点+词汇+阅读微技能+写作话题 |
| 四 | 命题DNA·命题解码 | 命题人想考什么？ | 选材趋势+设题策略+难度梯度+高考衔接特征 |
| 五 | 作战地图·行动转化 | 怎么拿分？ | 阅读策略+完形技巧+语篇填空语法清单+写作模板 |

- **观点态度**（Attitude/Purpose）：判断作者写作目的或态度

## 六、维度四：命题DNA·命题解码

### 输出格式

用「观察一/观察二/……」的卡片格式（`.card` + `.card.info/.success/.warning`），每条包含：
- **标题**（加粗，一句话概括命题特征）
- 具体说明 + 例证
- **备考启示→** 对学生的行动建议

### 命题DNA分析维度

1. **选材特征**
   - 4篇阅读+还原+完形+语篇+阅读表达 共8篇文本的话题覆盖度
   - 是否涉及辽宁本地/中国文化素材
   - 是否涉及前沿科技/社会热点
   - 文本真实性（是否改编自真实英文材料）

2. **设题策略**
   - 阅读理解16题中，细节/推理/主旨/词义各占几题
   - 是否出现"not mentioned"型干扰项
   - A篇是否最简单，D篇是否最难（难度梯度）
   - 阅读还原的衔接手段类型（代词/逻辑词/词汇复现）

3. **语法考查侧重**
   - 10空语篇填空中，时态/语态/词性转换/虚词的比例
   - 是否与高考语篇填空接轨
   - 无提示空格考查的虚词类型

4. **写作命题特征**
   - 话题是否贴近学生生活
   - 是否给出明确的写作要点（通常3个）
   - 是否限定体裁（书信/邮件/演讲稿等）
   - 与近年辽宁中考真题的关联度

5. **高考衔接特征**（辽宁改革重点）
   - 阅读还原（五选四）：直接对标高考新题型
   - 语篇填空：与高考语法填空题型一致
   - 开放性试题：要求用英语表达个人观点

| 题型 | 占比 | 策略 | 关键词 |
|------|------|------|--------|
| 细节理解 | ~60% | 题目关键词→原文定位→同义替换 | who/what/when/where/how |
| 推理判断 | ~20% | 根据已知信息+逻辑推理→排除法 | infer/learn/conclude |
| 主旨大意 | ~10% | 首段+末段+各段首句→归纳中心 | mainly about/best title |
| 词义猜测 | ~10% | 上下文语境+构词法+逻辑关系 | probably mean/closest to |

### 7.3 阅读还原解题策略

**解题步骤：**
1. **通读全文**，了解大意和结构
2. **分析空格位置**：段首（引出）/段中（衔接）/段尾（总结）
3. **寻找衔接线索**：
   - 代词回指（this/it/they → 指代前文什么）
   - 逻辑连词（however/besides/so → 前后什么关系）
   - 词汇复现（同一个关键词在空格前后出现）
   - 因果/递进/转折关系
4. **逐空匹配**，先做有明确线索的空
5. **验证**：代入后通读，检查逻辑是否通顺

### 7.4 完形填空解题策略

**解题步骤：**
1. **第一遍**：通读全文，把握故事大意和情感基调（不看选项）
2. **第二遍**：逐空填写，根据上下文语境选择
3. **第三遍**：代入检查，确保故事完整通顺

**核心技巧：**
- 动词辨析：看主语+宾语+语境
- 形容词辨析：看被修饰的名词+整句情感色彩
- 副词辨析：看所修饰的动词/形容词
- 利用**情感线索**：记叙文通常有情感变化（困难→转折→领悟）

### 7.5 语篇填空必备语法清单

**有提示填空（~7题）：**

| 语法点 | 变化规则 | 常见信号词 |
|--------|----------|------------|
| 一般过去时 | +ed/不规则 | last/ago/yesterday/at that time |
| 现在完成时 | have/has+pp | since/for/already/yet/ever |
| 被动语态 | be+pp | by/被动含义 |
| 最高级 | the+est/most | one of the/the+最高级 |
| 比较级 | +er/more | than/much+比较级 |
| 词性转换 | 名→形/形→副等 | 看空格在句中的成分 |
| 非谓语 | to do/doing/done | want/enjoy/finish/see sb do |
| 代词变格 | 主/宾/物主/反身 | 看空格在句中的位置 |
| 名词复数 | +s/es/不规则 | many/some/数字+复数 |

**无提示填空（~3题）：**

| 类型 | 常见答案 | 判断方法 |
|------|----------|----------|
| 冠词 | a/an/the | 名词前，首次提到a/an，特指the |
| 介词 | in/on/at/with/for/of | 固定搭配/时间地点介词 |
| 连词 | and/but/or/so/that | 前后句逻辑关系 |
| 代词 | it/they/this | 指代前文名词 |

### 7.6 书面表达高分策略

**通用结构模板（书信/邮件类）：**

```
Dear ...,
    [开头：表明写作目的/回应背景]
    [主体1：第一个要点 + 具体展开]
    [主体2：第二个要点 + 具体展开]
    [主体3：第三个要点 + 具体展开]
    [结尾：表达希望/祝愿/期待]
                                    Yours,
                                    XXX
```

**高分词汇替换表：**

| 基础词 | 高分替换 |
|--------|----------|
| good | excellent/wonderful/amazing |
| bad | terrible/awful/disappointing |
| like | enjoy/be fond of/be crazy about |
| very | extremely/incredibly/quite |
| think | believe/consider/hold the view that |
| important | essential/significant/vital |
| happy | delighted/pleased/thrilled |
| help | assist/give sb a hand/do sb a favor |

**高分句型：**
- 定语从句：I still remember the day when we...
- 状语从句：Although/Though..., ...
- 感叹句：What a wonderful time we had!
- 非谓语：Hearing the news, I felt...
- It句型：It is important/necessary for sb to do...
- not only...but also...

### 7.7 开放性试题（Q64）答题模板

**通用结构（30词以上）：**
```
I think what [人物] did is [评价词]. Because [原因1]. Also, [原因2/拓展].
I hope/wish [希望/感想].
```

**评价方向：**
- 人物品质类：brave/kind/selfless/patient/determined
- 行为评价类：meaningful/touching/inspiring/worth learning
- 个人感想类：I am deeply moved/I have learned that...

### 7.9 易错预警

| 题型 | 易错点 | 防范措施 |
|------|--------|----------|
| 阅读选择 | 答案与原文"近义替换"看不出 | 训练同义词识别能力 |
| 阅读选择 | 选了"原文出现但非正确答案"的干扰项 | 回到题目问的是什么 |
| 阅读还原 | 只看内容不看逻辑衔接 | 检查代词/连词是否衔接 |
| 完形填空 | 只看单空不看全文 | 先通读→再填空→再检查 |
| 语篇填空 | 时态判断错误 | 找时间状语确定时态 |
| 语篇填空 | 忘记第三人称单数 | 检查主语是否三单 |
| 语篇填空 | 被动语态漏写be动词 | 判断主语是"做"还是"被做" |
| 语篇填空 | one of the+最高级+复数名词 | 固定搭配死记 |
| 阅读表达 | Q64字数不足30词 | 写完数一数 |
| 阅读表达 | 答非所问 | 先审问题再找答案 |
| 书面表达 | 遗漏写作要点 | 逐条对照要点检查 |
| 书面表达 | 拼写错误/语法错误 | 写完检查一遍 |
| 书面表达 | 字数不足80词 | 每个要点展开2-3句 |
