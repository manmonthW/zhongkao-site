英语 · 考前速查卡

考前10分钟过一遍 · 基于10套辽宁模拟卷数据提炼 · 笔试90分钟（闭卷）· 听力口语30分另测

一、考试结构与时间分配（笔试90分钟·90分）

板块题量分值建议用时
阅读选择 A/B/C/D16题32分28min
阅读还原4题8分6min
完形填空10题10分8min
语篇填空（语法）10题10分8min
阅读与表达4题10分10min
书面表达1题20分20min
合计45题90分80min+检查10min
⚠️ 注意：听力口语30分为单独测试，不在笔试90分钟内。
时间分配铁律：阅读28min → 还原6min → 完形8min → 语法8min → 表达10min → 写作20min → 检查10min
作文必须留足20分钟！书面表达20分是全卷最大分值单项。

二、阅读理解攻略（40分 · 最大板块）

体裁锁定铁律（10套验证）

篇章主导体裁出现率阅读策略
A篇应用文90%扫读定位——找时间/地点/价格/联系方式
B篇记叙文70%抓情感线——谁+做了什么+为什么+结果
C篇说明文70%抓总分结构——首段主旨+各段首句
D篇说明文60%最难篇——不确定选项先跳过回头做

题型三级分层（160题统计）

梯队题型占比秒杀技巧
第一梯队细节理解50%题干关键词 → 原文定位 → 同义替换
第一梯队推理判断14%文中有据不脑补，选最接近原文的
第二梯队标题/主旨/文体18%标题→各段首句汇总；文体→四大特征词
第二梯队词义猜测5%上下文线索 + 构词法（前缀/后缀）
第三梯队代词指代/写作手法等13%代词→往前找最近名词；手法→举例/对比/数据
阅读还原（8分）三步法：
  • 第一步：先通读全文，标出每个空的前后句
  • 第二步：先做最确定的空（有明显代词/连词线索的）
  • 第三步：剩余用排除法，代入验证上下文是否通顺

三、完形填空秒杀（10分）

铁律：10套卷中9套完形是记叙文，全是"少年成长故事"。
解题密码 = 找到情感转折点！（恐惧→勇敢 / 浮躁→耐心 / 被忽视→理解）
完形三步法：
第一步 · 通读：跳过空格读全文，找出"谁+发生了什么+结局"
第二步 · 定调：找到情感转折点（通常在第2-3段），确定前后情感方向
第三步 · 填空：83%的题靠语境推理——代入选项看哪个最通顺

完形选项词类分布（100题统计）

词类占比解题提示
动词/动词短语33%看主语→判断"谁做了什么"→排除语义不通的
名词25%看前后修饰语，结合语境
形容词23%情感转折点处最常考，判断正面/负面
副词16%修饰动词/形容词，看程度/方式
完形易错：
  • 不要只看空格所在句——必须看前后2句才能确定语境
  • 动词短语：deal with(处理) / look forward to(期待) / give up(放弃) / turn out(结果是)

四、语法填空高频考点（10分）

无提示 · 虚词铁三角（每卷必考3分）

考点频次秒杀口诀
冠词 a/an/the10/10特指→the；泛指→a/an；球类/三餐/语言→零冠词
介词10/10时间in/on/at；搭配be famous for/be good at
连词9/10因果because/so；转折but/however；条件if/when

有提示 · 词形变化五大金刚

考点频次判断方法
被动语态 be+done9/10主语是"被做"的 → am/is/are/was/were + 过去分词
词性转换9/10空格在名词前→要形容词；在动词后→要副词(-ly)
名词复数8/10前面有many/some/数词/these → 加-s/-es
非谓语 to do7/10want/decide/hope/plan/need + to do
一般过去时6/10有last/ago/yesterday/in 2020等过去时间标志词→+ed
判断口诀"被词名非过"：看到有提示词 → 按被动→词性→名词复数→非谓语→过去时这个顺序排查

语法填空选材：8/10以中国文化为载体（围炉煮茶/元宵节/清明上河图/太极拳/白露/春晚...）

五、书面表达万能框架（20分）

体裁铁律：7/10套是书信/邮件！Dear ___,开头 + Yours, 结尾 + 三段式。

三段式万能结构

开头段（2句）：I'm writing to tell you about... / I'm glad to hear from you. + 引出话题

主体段（3-4句）：First, ... Second, ... What's more, ... + 分点展开要点

结尾段（1-2句）：I hope you will... / I'm looking forward to your reply.

高分替换词（避免重复用good/very/like）

基础词高分替换
goodexcellent / wonderful / amazing / fantastic
veryreally / extremely / quite / deeply
likeenjoy / be fond of / be interested in / be crazy about
thinkbelieve / consider / in my opinion / as far as I know
importantsignificant / essential / vital / of great importance
becausesince / as / thanks to / owing to

加分句型（用2-3个即可）

① not only...but also... 不仅……而且……
② It is + adj. + for sb. to do sth. 做某事对某人来说是……
③ so...that... 如此……以至于……
④ the + 比较级, the + 比较级 越……就越……
⑤ 定语从句 ...which/who/that...
⑥ I believe that... 宾语从句表达观点

六、阅读与表达拿分技巧（10分）

题型分布：细节提取(~6分) + 开放性表达(~4分)
细节提取：问什么答什么，用原文信息简洁回答，不要抄整段
开放性表达（4分拉分关键）：
  • 30词左右，不要太长也不要太短
  • 固定模板：I think + 观点 + First, ... Second, ...
  • 紧扣文章主题，不要跑题

七、考场救命锦囊

做题顺序建议：
阅读ABCD → 阅读还原 → 完形 → 语法 → 阅读表达 → 书面表达
不要先做写作——写作放在最后，前面拿到的信息可能启发写作思路
阅读做不完怎么办：
· D篇最难——如果时间紧，D篇每题花30秒排除2个选项后猜
· 阅读还原——做最有把握的2题（4分），不确定的用排除法
· 绝不因为阅读占用写作时间——阅读每题2分，写作20分
写作检查清单：
□ 格式对吗？（Dear/Hi开头，Yours结尾）
□ 要点全覆盖了吗？（对照题目逐条检查）
□ 时态一致吗？（过去→过去；建议→一般现在）
□ 字数够吗？（通常要求80词左右，写90-100词最安全）
□ 有没有用到2-3个高分句型？
最后5分钟检查清单：
□ 阅读选择有没有漏涂？
□ 完形填空有没有空着没填的？
□ 语法填空有没有写错位置？
□ 书面表达有没有明显拼写错误？
□ 姓名考号写了吗？
