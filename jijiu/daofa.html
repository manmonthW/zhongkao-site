二、选择题秒杀技巧

绝对化排除法（几乎每卷出现）
选项中出现"只有""唯一""一定""完全""绝对"→ 直接排除
例如："只有获得冠军才能实现人生价值" × → 明显绝对化
高频混淆点（必须区分清楚）
· 批准规划 = 决定权（不是立法权）
· 制定法律 = 立法权
· 听取法院/检察院报告 = 监督权（不是决定权）
· 全国人大 = 最高国家权力机关（不是行政机关）
· 国有经济 = 国民经济主导力量
· 公有制经济 = 国民经济主体
审题陷阱：看到"搭配错误的是"→ 反选题！选错的而非对的。6套卷中沈河Q13就是这类。

四、国情国策核心链（背住=35分底盘）

经济建设

  • 改革开放 = 决定中国命运的关键抉择
  • 共同富裕 = 中国特色社会主义的本质要求
  • 国有经济 = 国民经济主导力量

政治制度

  • 党的领导 = 中国特色社会主义最本质的特征 + 最大优势
  • 协商民主 = 社会主义民主政治的特有形式和独特优势
  • 民族关系 = 平等 + 团结 + 互助 + 和谐

文化自信

  • 中华文化 = 创造力和包容力（两个都要写）
  • 推动创造性转化、创新性发展
  • 坚定文化自信

科技创新

  • 三大战略 = 创新驱动 + 科教兴国 + 人才强国
  • 人才是第一资源
  • 国际竞争实质 = 以经济和科技为基础的综合国力较量

绿色发展

  • 处理好经济发展与生态环境保护的关系
  • 保护环境 = 基本国策

五、开放写作万能结构（4分题通用）

模板（写4点即可满分）：

① 我们要积极学习……（学习层面）

② 我们要培养……意识/精神（意识层面）

③ 我们要积极参加……实践活动（行动层面）

④ 我们要从身边小事做起……（日常层面）

3套现成模板直接套

类型四步写法
文化贡献学习经典 → 坚定文化自信 → 参加文化传承活动 → 讲好中国故事
创新能力学习科学知识 → 培养好奇心批判思维 → 参加科创实践 → 敢于质疑探究
绿色生活学习环保知识 → 增强环保意识 → 参加环保志愿活动 → 节水节电垃圾分类

六、开卷翻书策略

考前准备：用便利贴给课本贴6个标签——宪法 · 人大 · 国安 · 经济 · 文化 · 生态

考场规则：
· 识记类（国有经济/时代主题/兵役义务）→ 翻书确认，每题30秒
· 理解类（行政违法/决定权vs立法权）→ 翻书找不到答案，靠理解判断
· 材料提取类（"从材料中举例"）→ 答案在材料中，不在课本里
