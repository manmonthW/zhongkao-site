数学 · 考前速查卡

考前10分钟过一遍 · 基于11套辽宁模拟卷数据提炼 · 闭卷120分120分钟

一、考场时间分配（先刻进脑子）

阶段题号时间策略
选择题Q1-Q10（30分）20分钟前8题秒杀，Q9-Q10可跳过回头做
填空题Q11-Q15（15分）15分钟Q14-Q15难度高，不会就跳

铁律：遇到卡壳的题，超过3分钟立刻跳过，做完全卷再回来。基础题的分丢了补不回来！

二、必拿分清单（约70分基础题）

这些题型11套卷全部出现，送分题必须零失误：
· 科学记数法（选择前3题）→ 大数：小数点移到个位数后面，指数=移动位数
· 整式运算/乘法公式（选择前5题）→ 逐项验证，别心算
· 三视图（选择题）→ 主视图=正面看，俯视图=上面看
· 轴对称/中心对称判断（选择题）→ 轴对称=折叠重合，中心对称=旋转180°重合
· 概率计算（选择/填空）→ 列举法不要漏
· 实数综合计算（Q16第1题，5分）→ 零指数幂=1，负数幂先算幂再加负号
· 分式化简求值（Q16第2题，5分）→ 先因式分解再约分，最后代入
· 统计图表（Q17/Q18，6-8分）→ 补图+中位数+估计总体，最容易拿满分的解答题

实数运算常见陷阱

考前默念三遍：
· (-2)² = 4  但  -2² = -4  → 括号决定一切
· (-3)⁰ = 1  但  0⁰ 无意义 → 零指数幂底数≠0
· |−5| = 5 → 绝对值出来一定是非负数
· √4 = 2（不是±2）→ 算术平方根只取正值

因式分解两大方法

  • 提公因式法：ma + mb = m(a+b) → 先提再看
  • 公式法：a²−b² = (a+b)(a−b)；a²±2ab+b² = (a±b)²
分式方程必须检验增根！把解代回原方程的分母，分母=0则为增根，必须舍去。11套卷中分式方程题全部需要检验。

三、公式速记卡

一元二次方程

求根公式：x = (−b ± √(b²−4ac)) / 2a
判别式 Δ = b²−4ac：Δ>0 两个不等实根 · Δ=0 两个相等实根 · Δ<0 无实根
韦达定理：x₁+x₂ = −b/a，x₁·x₂ = c/a

二次函数（11套卷第23题全考）

一般式：y = ax² + bx + c（a≠0）
顶点式：y = a(x−h)² + k，顶点(h, k)
对称轴：x = −b/(2a)
开口方向：a>0 开口向上（有最小值）· a<0 开口向下（有最大值）
与x轴交点：令y=0解方程 · 交点距离 = √(Δ)/|a|

圆的公式

弧长：l = nπr/180（n为圆心角度数）
扇形面积：S = nπr²/360 = ½lr
圆周角定理：同弧上的圆周角 = 圆心角的一半
切线判定：经过半径外端且垂直于半径 → 是切线
切线性质：切线⊥过切点的半径

勾股定理 + 特殊三角形

勾股定理：a² + b² = c²（c为斜边）
常用勾股数：3-4-5、5-12-13、8-15-17 及其倍数（6-8-10等）
30°-60°-90°：边比 = 1 : √3 : 2（30°对的边最短）
45°-45°-90°：边比 = 1 : 1 : √2

特殊角三角函数值（解直角三角形必用，10/11卷考）

角度sincostan
30°1/2√3/2√3/3
45°√2/2√2/21
60°√3/21/2√3

相似三角形

对应边成比例：a₁/a₂ = b₁/b₂ = c₁/c₂ = k（相似比）
面积比 = 相似比的平方：S₁/S₂ = k²
周长比 = 相似比：C₁/C₂ = k

四、压轴题应急策略

第22题 · 几何压轴（12分，旋转/翻折二分天下）

第(1)问（4分）· 必拿：证明全等或相等 → 找对应边对应角，写清SAS/ASA/AAS

第(2)问（4分）· 尽力：求线段或面积 → 利用第(1)问结论，构造直角三角形或用勾股定理

第(3)问（4分）· 量力：综合探究 → 如果没思路，把第(1)(2)问的结论写上去，尝试建系或特殊值

旋转题口诀：旋转中心不动，对应线段相等，对应角相等，旋转角=对应点连线夹角
翻折题口诀：折叠前后全等，对应点到折痕距离相等

第23题 · 代数压轴（13分，63%为新定义题）

第(1)问（3-4分）· 必拿：求解析式或基本性质 → 待定系数法，送分题

第(2)问（4-5分）· 尽力：利用函数性质解题 → 画图辅助理解

第(3)问（4-5分）· 新定义核心：先读懂定义（读3遍！），把新概念翻译成方程或不等式，再分类讨论

新定义题三步法：
① 读定义：把文字翻译成数学语言（等式/不等式）
② 套定义：代入具体函数，列方程
③ 分类讨论：按参数范围或图象位置分情况，不要漏情况！

五、易错点 TOP10（基于11套卷数据）

#易错点正确做法
1(-2)² 和 -2² 搞混有括号=底数是-2，结果4；无括号=先算2²再加负号，结果-4
2分式方程忘记检验增根解出来必须代回原分母，分母=0就舍去
3二次函数实际问题不写取值范围自变量x的范围由实际意义决定（长度>0、数量为整数等）
4切线证明条件不全必须同时满足：① 过半径外端 ② 垂直于半径，缺一不可
5动点问题分类讨论漏情况画图标出动点所有可能位置，逐一讨论
6科学记数法指数写错大数：2.5×10⁸（小数点移8位）· 小数：3×10⁻⁴（小数点移4位）
7√ 里面出负数没发现二次根式被开方数≥0，分母≠0，做完检查一遍
8统计题中位数找错先排序！奇数个取中间，偶数个取中间两个的平均值
9解直角三角形选错三角函数对边/斜边=sin · 邻边/斜边=cos · 对边/邻边=tan
10几何证明跳步每一步都要写理由（定理名称），不能"显然可得"

六、考场救命锦囊

选择题实在不会？试试这些：
· 特殊值法：代入简单数字（0、1、-1）排除选项
· 排除法：先排掉明显错误的，剩2个再细看
· 画图法：函数题画草图，几何题画辅助线
· 量力而行：Q9-Q10是选择压轴，不确定就选最可能的，不要死磕
解答题拿分技巧：
· 写"解"和"证明"：格式分不能丢
· 压轴题第(1)问一定要做：第22题和第23题的第(1)问合计7-8分，是送分题
· 不会做也要写：写出已知条件、画出图形、列出相关公式，阅卷老师会给过程分
· 分类讨论写"综上所述"：最后汇总所有情况的答案
最后5分钟检查清单：
□ 科学记数法的指数对不对？
□ 分式方程写了"经检验"没有？
□ 二次函数实际问题写了取值范围没有？
□ 概率题列举法有没有漏？
□ 答案有没有写在答题卡上？
