二、方程式速记卡（高频TOP15）

🔴 气体制取（11/11卷必考）

实验室制O₂：2KMnO₄ →加热 K₂MnO₄ + MnO₂ + O₂↑
催化制O₂：2H₂O₂ →MnO₂ 2H₂O + O₂↑
实验室制CO₂：CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑

🔴 燃烧与氧化（10/11卷考查）

碳完全燃烧：C + O₂ →点燃 CO₂
铁在氧气中燃烧：3Fe + 2O₂ →点燃 Fe₃O₄
镁燃烧：2Mg + O₂ →点燃 2MgO

🟡 金属活动性/置换（9/11卷涉及）

铁与硫酸铜：Fe + CuSO₄ → FeSO₄ + Cu
铁与盐酸：Fe + 2HCl → FeCl₂ + H₂↑（注意是+2价）
锌与稀硫酸：Zn + H₂SO₄ → ZnSO₄ + H₂↑

🟡 酸碱盐反应（8/11卷涉及）

中和反应：NaOH + HCl → NaCl + H₂O
CO₂+NaOH：CO₂ + 2NaOH → Na₂CO₃ + H₂O（NaOH变质原因）
碳酸盐检验：Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑
石灰水验CO₂：Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O
方程式三必查：① 配平了吗？ ② 条件标了吗（加热/点燃/催化剂）？ ③ ↑↓标了吗？

三、选择题秒杀指南（10题10分）

Q1-Q3 送分题（30秒/题）

考点出现率秒杀技巧
化学用语11/112Mg²⁺=2个镁离子；Al₂O₃中Al为+3价
实验基本操作11/11倾倒液体标签朝手心；加热试管口略向下
营养物质分类8/11糖类供能；蛋白质=鱼肉蛋奶豆；维生素=蔬果

Q4-Q7 中档题（1min/题）

考点出现率秒杀技巧
元素周期表信息10/11左上角=原子序数=质子数；相对原子质量无单位"g"
物质分类10/11氧化物=两元素+含氧；混合物≠含两种元素
燃烧灭火10/11"降低着火点"是错的！着火点是固有属性不能降低
金属/合成材料8/11合金=混合物；塑料/橡胶/纤维=三大合成材料

Q8-Q10 选择压轴（2min/题）

考点出现率策略
溶解度曲线10/11交点=同温同溶解度；陡升→降温结晶；缓升→蒸发结晶
微观示意图8/11数原子个数→验证质量守恒→判断反应类型
化学式计算9/11相对分子质量、元素质量分数、元素质量比
选择题经典陷阱：
  • "降低可燃物的着火点" → ❌ 着火点不能被降低
  • "相对原子质量单位是g" → ❌ 无单位（或单位为1）
  • "氧化物一定含氧" → ✓ 但含氧不一定是氧化物（如KMnO₄）
  • "饱和溶液一定是浓溶液" → ❌ Ca(OH)₂饱和但很稀

四、实验题应急模板

Q11 气体制取（9/11卷核心）

装置选择口诀：
固+固加热 → 选A装置（如KMnO₄制O₂）
固+液常温 → 选B装置（如H₂O₂制O₂、CaCO₃+HCl制CO₂）
收集方法：排水法（不易溶于水）| 向上排空气法（密度>空气）| 向下排空气法（密度<空气）
CO₂验满：燃着木条放瓶口，熄灭则满
O₂验满：带火星木条放瓶口，复燃则满

Q14 综合探究（定量计算）

化学方程式计算四步法：
① 写出配平的化学方程式
② 标出相关物质的相对分子质量和已知/未知量
③ 列比例式
④ 求解并写答（注意单位g）
溶质质量分数公式：
溶质质量分数 = 溶质质量 ÷ 溶液质量 × 100%
溶液质量 = 溶质质量 + 溶剂质量
稀释公式：浓溶液质量 × 浓度 = 稀溶液质量 × 稀释后浓度

五、科普阅读应急三步法

题材完全不可预测（11套卷题材全不同）：分子筛、单原子催化、石墨烯、脑机接口、锂电池回收、氢燃料电池、荔枝保鲜……
但答题套路是固定的：
第一步 · 快速定位：先看题目问什么 → 回文中找关键句（通常就在对应段落）
第二步 · 知识迁移：用学过的知识解释文中新概念（最常考化学方程式书写）
第三步 · 图表分析：有图表必考数据读取 → 找最大值/最小值/变化趋势

常见设问类型：
① 从文中提取信息回答（原文照抄即可）
② 结合图表数据分析（读数+对比）
③ 写出相关化学方程式（最高频）
④ 判断说法正误（对照原文逐项核对）

六、易错点TOP8

序号易错点正确说法
1着火点可以降低❌ 着火点是物质固有属性，不能改变
2催化剂改变了反应速率和生成物质量❌ 催化剂只改变速率，质量和化学性质不变
3Fe与盐酸→FeCl₃❌ 铁与酸反应生成+2价的FeCl₂，不是FeCl₃
4饱和溶液=浓溶液❌ Ca(OH)₂饱和溶液浓度很低
5CO₂使石蕊变红❌ 是CO₂+H₂O→H₂CO₃，碳酸使石蕊变红
6氧化物=含氧化合物❌ 氧化物=两种元素+其中一种是氧，KMnO₄不是氧化物
7稀释浓硫酸：水倒入酸❌ 必须酸入水，沿壁缓慢倒入并搅拌
8过滤可以除去所有杂质❌ 过滤只除去不溶性杂质，溶解的杂质无法过滤

七、考场救命锦囊

物化合卷节奏：
· 建议先做物理再做化学（物理题量大需要头脑清醒）
· 化学50分钟足够，不要因为物理用时过多而压缩化学
· 做完物理立刻看表，确认化学剩余时间 ≥ 50分钟
选择题检查技巧：
· Q1-Q3基础题：有把握就不改，第一印象通常对
· Q8-Q10压轴题：可以用排除法——明确排除2个选项后剩下的大概率对
· 全部10题只有10分，不值得花超过8分钟
非选择题拿分策略：
· Q11写出化学方程式就有分，装置选择题写出理由就有分
· Q12每空独立给分，不会的跳过，会的写满
· Q13先找原文答案，再写需要推理的
· Q14计算题写出步骤就给过程分，即使最终答案错了
最后3分钟检查清单：
□ 化学方程式配平了吗？条件和↑↓标了吗？
□ 计算题单位写"g"了吗？
□ 选择题有没有漏涂答题卡？
□ Q11实验装置选择有没有写理由？
