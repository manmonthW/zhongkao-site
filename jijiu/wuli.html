二、公式速记卡（必须烂熟于心）

力学核心

G = mg（g = 10 N/kg）
p = F/S（固体压强，单位Pa）
p = ρgh（液体压强，深度h从液面往下量）
F浮 = ρ液gV排（阿基米德原理）
F浮 = G（漂浮/悬浮条件）
W = Fs（做功，F和s方向必须一致）
P = W/t = Fv（功率）
η = W有/W总（机械效率）

电学核心

U = IR（欧姆定律）
P = UI = I²R = U²/R（电功率三公式）
W = UIt = Pt（电功）
Q = I²Rt（焦耳定律，纯电阻Q=W）

热学核心

Q = cmΔt（c水 = 4.2×10³ J/(kg·℃)）
Q = mq（q为热值，完全燃烧）
η = Q吸/Q放（热效率）
三个必记常数：g = 10 N/kg　|　ρ水 = 1.0×10³ kg/m³　|　c水 = 4.2×10³ J/(kg·℃)

六、综合计算题分步得分模板

Q22 力学计算（7-10分）

第一步（送分）：G = mg 或 p = F/S → 写公式+代数+单位 ≈ 3分
第二步：p = ρgh 或 F = pS → 液体压强/受力面积 ≈ 2-3分
第三步：W = Fs → P = W/t 或 η = W有/W总 ≈ 2-3分
情境特点：7/11套用工程/科技情境（塔吊/滑轮组/洒水车/半潜船/深海空间站）

Q23 电学计算（6-8分）

第一步（送分）：U = IR 或 P = UI → 基本电学量 ≈ 2分
第二步：W = UIt 或 Q = cmΔt → 电功/热量 ≈ 2-3分
第三步：η = Q吸/W → 效率计算 ≈ 2分
情境特点：7/11套是家用电器（饮水机/电蒸锅/电水壶/加湿器），4套纯电路

Q24 STEM题（6-7分）

不要放弃STEM！前几问是概念填空，通常3-4分可稳拿：
  • 第一问通常是基础概念/物理量判断（送分）
  • 第二问通常是简单计算或现象分析
  • 最后一问才是综合设计题（可以战略放弃）

七、易错点TOP10（11套卷高频陷阱）

序号易错点正确说法
1惯性越大速度越大❌ 惯性大小只与质量有关，与速度无关
2力是维持运动的原因❌ 力是改变运动状态的原因
3液体压强与容器形状有关❌ p=ρgh 只与深度和液体密度有关
4做功一定产生热量❌ 做功可以改变内能，但不一定产生"热量"
5沸点是100℃❌ 标准气压下才是100℃，气压低沸点低
6串联电路电压处处相等❌ 串联电流处处相等，电压按电阻分配
7灯泡越亮电阻越大❌ 亮度取决于实际功率P=UI，不是电阻
8物体下沉说明浮力=0❌ 下沉是F浮
9平面镜所成像大小可变❌ 像与物等大，走近只是视角变大
10升华需要先变成液体❌ 升华是固态直接变气态，跳过液态

八、考场救命锦囊

物化合卷时间调控：
· 先做物理（85-90min），再做化学（50-55min），留10min机动
· 物理做完标记不确定的题号，化学做完后回来检查
· 绝对不能在Q9多选上卡超过5分钟！选最有把握的就走
计算题分步拿分：
· 写出公式 = 1分
· 代入数据 = 1分
· 算出结果+写单位 = 1分
· 即使最终答案算不对，公式+代入至少拿2分
作图题规范：
· 光路图：入射光线/反射光线/折射光线都要画箭头，法线用虚线
· 力的示意图：作用点画在物体受力点上，箭头方向+力的符号
· 力臂：从支点到力的作用线的垂直距离，画虚线标垂直符号
最后5分钟检查清单：
□ 多选题有没有漏选/错选？不确定的宁可少选
□ 计算题单位写了吗？（Pa / N / J / W）
□ p=ρgh的h用的是深度而不是高度？
□ 电学计算中串并联关系搞对了吗？
□ 答案有没有写在答题卡上？
