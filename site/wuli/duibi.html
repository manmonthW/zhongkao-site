🔍 实验题重大发现（11套验证）：
  1. 热学实验三分天下：水沸腾5套 / 冰熔化3套 / 无热学3套。水沸腾不再是100%必考。
  2. 密度测量超越水沸腾，成为力学最高频实验（6/11套），方法多样：天平+量筒/浮力法/漂浮法/测力计法。
  3. 光学二选一：平面镜成像(4套) vs 凸透镜成像(6套)，铁岭无光学实验。
  4. 电学实验核心：I与U/R关系(5套) 或 伏安法(3套) 或 特殊(压敏电阻/电热/测灯泡R)。
  5. 铁岭最大偏差：力学×2+电学×2，完全无光学和热学实验。

八、备考策略总纲

第一优先级：保基本盘（~50分）

  • 选择Q1-Q6（12分）：物态变化+光学+安全用电+力学概念+声学，全是基础概念。
  • 填空Q10-Q14（10分）：参照物/电磁波/比热容/惯性/安全用电，每空1分。
  • 作图Q16-Q17（4分）：光路图+力的示意图/力臂，掌握规范画法。
  • 实验基本操作（~10分）：组装顺序/读数/控制变量。
  • 综合Q22第一问（~3分）：G=mg 或 p=F/S，几乎送分。
  • 综合Q23第一问（~2分）：U=IR 基本电学计算。

第二优先级：争中间分（~20分）

  • 选择Q7-Q8（4分）：多选漏选得1分——只选最确定的。
  • 填空Q15（2分）：浮力/压强/密度计算，难度高。
  • 实验深层问（~8分）：故障排查/图像分析/实验改进。
  • 综合Q22-Q23后续（~8分）：η/P/W/Q完整计算。

第三优先级：冲高分（~10分）

  • Q9 电学压轴多选（2分）：画等效电路逐项分析。
  • 实验创新拓展（2-3分）：密度秤/电阻箱/实验改进。
  • Q24 STEM题（6-7分）：前几问概念填空3-4分可稳拿。

  • 水沸腾实验不再是100%必考——仅5/11套考了。冰熔化3套。还有3套无热学实验。
