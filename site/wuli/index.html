实验题命题规律（占比30%·~24分）

密度测量超越水沸腾，成为力学最高频实验

  • 密度测量（6/11套）：天平+量筒法 / 浮力法 / 漂浮法 / 测力计法——方法最多样
  • 水沸腾（5/11套）：不再100%必考！冰熔化3套，3套无热学实验
  • 光学二选一：凸透镜成像（6套） vs 平面镜成像（4套），铁岭无光学实验
  • 电学核心：I与U/R关系（5套） / 伏安法（3套） / 特殊实验（3套）
  • 铁岭最大偏差：力学×2+电学×2，完全无光学和热学实验

综合应用题命题趋势

Q22 力学计算（7-10分）：必含 p=F/S 或 p=ρgh

  • 塔吊 · 滑轮组 · 卷扬机 · 洒水车 · 氢气汽车（10分最高） · 半潜船 · 深海空间站
  • 第一问几乎送分：G=mg 或 p=F/S → 后续问W/P/η逐步提升

Q23 电学计算（6-8分）：64%家用电器情境

  • 家用电器（7套）：饮水机 · 电蒸锅 · 电水壶×3 · 蚊香器 · 加湿器
  • 纯电路（4套）：沈北/铁西/铁岭/苏家屯 → 必含 U=IR + P=UI

Q24 STEM综合（6-7分）：跨学科·每套主题独特

  • 智能设备类：晾衣架（皇姑）· 垃圾箱（铁西）· 消防机器人7考点（沈北）
  • 能源类：太阳能+潮汐（沈河）· 超充桩（苏家屯）· 电力发展史（营口）
  • 科考类：雪龙2号（和平）· 水肺潜水（浑南）· 光学测沙仪（抚顺）
  • 前几问概念填空通常3-4分可稳拿，不要放弃！

选择题铁律

Q9 电学压轴多选：100% 考欧姆定律+电功率综合

11套试卷Q9全部是电学综合计算多选，全卷选择最难，无一例外。
策略：画等效电路，逐项分析串并联电路状态变化——只选最确定的选项，漏选得1分。

备考策略·三级优先

第一优先·保基本盘（~50分）

  • 选择Q1-Q6（12分）：物态变化+光学+安全用电+力学概念+声学
  • 填空Q10-Q14（10分）：每空1分，参照物/电磁波/比热容/惯性/安全用电
  • 作图Q16-Q17（4分）：光路图+力的示意图/力臂
  • 实验基本操作（~10分）：组装顺序/读数/控制变量
  • Q22-Q23第一问（~5分）：G=mg / p=F/S / U=IR 几乎送分

第二优先·争中间分（~20分）

  • 多选Q7-Q8（4分）：漏选得1分——只选最确定的
  • 填空Q15（2分）：浮力/压强/密度计算，难度高
  • 实验深层问（~8分）：故障排查/图像分析/实验改进
  • Q22-Q23后续（~8分）：η/P/W/Q完整计算

第三优先·冲高分（~10分）

  • Q9电学压轴多选（2分）：画等效电路逐项分析
  • 实验创新拓展（2-3分）：密度秤/电阻箱/实验改进
  • Q24 STEM题（6-7分）：前几问概念填空3-4分可稳拿
