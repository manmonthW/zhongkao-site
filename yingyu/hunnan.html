维度四 · 命题DNA（命题解码）

观察一 · 选材高度聚焦"中国故事"——6/9篇涉及中国题材

国家公园(A篇)、粮食安全(B篇)、教育部体育政策(还原)、上海老年商店(D篇)、广州近零能耗大楼(阅读与表达)、元宵节(语篇填空)。体现"用英语讲中国故事"的命题导向。备考启示→重点积累中国科技/政策/文化/社会话题的英文表达，如national park、grain production、solar panel、exoskeleton等。

观察二 · 细节理解占半壁江山但设题方式多样化

16道阅读选择中细节理解8题(50%)，但设题方式不再是简单原文定位：Q22需通过面积数据计算百分比(210.7/1280≈16%)，Q26需归纳"sharing technology"方式，Q31需理解"反面应对→正面建议"的逻辑。表面考细节，实则考信息加工能力。备考启示→训练"带着问题精读+同义替换识别+数据推算"三合一能力。

观察三 · 语篇填空"有提示7+无提示3"黄金比例——语法覆盖全面

有提示7题覆盖：最高级(most important)、被动语态(are made)、不定式(to eat)、主谓一致(agrees)、词性转换(simply)、名词复数(lines)、反身代词(themselves)。无提示3题：冠词(the)、连词(or)、介词(by)。语法点分布均匀，无偏难怪题。备考启示→重点攻克"被动语态+主谓一致+不定式"三大高频考点。

观察四 · 完形填空动词占50%——与和平区形容词主导形成差异

本卷完形10题中动词/动词短语5题(enjoying/reach/called for/praised/told)，名词3题，形容词和副词各1题。动词题需根据动作逻辑链（度假→遇险→游泳→求救→获救→讲述）选择。备考启示→完形记叙文要抓住"事件发展顺序"，动词短语(call for/prepare for/wait for/pay for)是必考点。

维度五 · 作战地图（行动转化）

🎯 P0 · 阅读选择拿下24-28分（满分32分）
  • A篇(说明文·图文)：3分钟速读，重点关注数字(面积/比例)和地理信息，注意计算题
  • B篇(说明文·时事)：抓住每段首句(achievement→help→technology)，态度题全文定基调
  • C篇(议论文)：先读题干关键词，回原文段落精确定位；词义猜测题看前后文逻辑
  • D篇(新闻报道)：who/what/where/why四要素快速抓取，推理题需归纳而非原文照搬
  • 时间分配：A篇5分钟 + B篇7分钟 + C篇8分钟 + D篇8分钟 = 28分钟内完成
⚡ P1 · 书面表达冲刺15-18分（满分20分）
  • 审题三步：①体裁=邮件回复 ②要点=祝贺+分享经历 ③时态=回忆用过去时/感受用现在时
  • 本卷难度适中："small victory"话题贴近学生生活，演讲比赛/考试进步/学会技能均可写
  • 高分模板：第1段祝贺(2-3句) → 第2段自己的经历(4-5句，有细节) → 第3段鼓励+期望(2句)
  • 必备句型：Congratulations on... / I still remember when... / I was so...that... / Keep up the great work!
📌 P2 · 语篇填空稳拿7-9分（满分10分）
  • 有提示(7题)：看括号词→判断变什么(时态/语态/词性/级别)→检查主谓一致
  • 无提示(3题)：判断缺什么成分→冠词(the/a)/介词(by/in/of)/连词(or/and/but)三选一
  • 必背规律：the same(固定搭配) / difficult to do(adj.+to do) / everyone+单三 / by doing(方式)
  • 检查清单：①是否需要最高级 ②是否被动语态 ③第三人称单数-s ④名词是否需要复数
🧩 P3 · 完形填空+阅读还原拿下13-16分（满分18分）
  • 完形(记叙文)：①通读把握"海滩遇险→勇敢自救→全家获救"主线 ②动词题按时间顺序选 ③名词题看搭配(have no choice but to / called for help)
  • 还原(政策说明)：先做线索最明确的空(Q38"两套课表"→E最确定)，再用排除法做其他空
  • 还原核心技巧：代词指代(They→前文谁) / 因果连词(So→前因后果) / 时间推进(later→展望)
  • 本卷还原难度：★★☆ 逻辑线索清晰，多余项C(安全担忧)与政策方向不匹配易排除
