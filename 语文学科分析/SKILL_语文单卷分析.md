# 语文单卷深度分析 Skill（五维分析模型）

> 适用于：辽宁中考语文模拟卷逐卷分析
> 输入：OCR文本 + 答案（如有）
> 输出：单张HTML页面，内嵌CSS，无外部依赖

---

## 一、分析框架总览

语文试卷分析的核心特征（与数学/物理的根本差异）：
- **阅读是灵魂**：现代文阅读36分+古诗文阅读17分=53分，占总分44%
- **写作是半壁江山**：作文50分，单题分值占全卷42%
- **无公式无计算**：考查的是语言理解、鉴赏、表达能力，分析重点在「答题模板」而非公式链
- **四大板块固定**：积累运用 / 古诗文阅读 / 现代文阅读 / 写作
- **情境化命题是标配**：辽宁地域素材+社会热点+传统文化深度嵌入

五个维度：

| 维度 | 名称 | 核心问题 | 语文特色 |
|------|------|----------|----------|
| 一 | 试卷结构与分值画像 | 这张卷子长什么样？ | 四大板块分值 + 选文概览 + 作文题型 |
| 二 | 核心考点与知识分布 | 考了哪些知识？ | 按板块梳理考点标签 + 选文/篇目/名著详情 |
| 三 | 逐题映射与能力评估 | 每道题考什么能力？ | 逐题表（考点/能力维度/教材定位/分值）+ 四模块风险评估 |
| 四 | 命题特征与趋势研判 | 命题人想考什么？ | 命题DNA逐条提炼 + 趋势判断 |
| 五 | 提分策略与落地方案 | 怎么拿分？ | 优先级排序 + 易错预警 + 分数规划 + 答题模板 |

## 二、维度一：试卷结构与分值画像

### 输出内容

1. **基本参数 KPI 卡片**（8个）
   - 积累与运用：XX分（Q1-Q5）
   - 古诗文默写：含Q5默写6分
   - 古诗阅读：QX（3-5分）
   - 文言文阅读：QX-QX（14分）
   - 非连续性文本：QX-QX（8分）
   - 记叙文阅读：QX-QX（17分）
   - 议论文/说明文阅读：QX-QX（11分）
   - 写作：QX（50分）

2. **结构特征总结**（ul列表）
   - 板块完整性：是否覆盖积累运用+古诗文+三类现代文+写作
   - 辽宁地域素材：标注本卷使用的辽宁/沈阳本地素材
   - 能力梯度：识记→理解→分析→综合→表达的递进关系
   - 写作题型：命题作文/半命题/材料作文/话题作文，二选一的两个方向
   - 积累运用整合度：是否在统一语段中整合考查

### 关键数据参考（12套卷统计）

| 板块 | 分值 | 占比 |
|------|------|------|
| 写作 | 50分 | 42% |
| 现代文阅读 | 36分 | 30% |
| 古诗文阅读 | 17分 | 14% |
| 积累与运用 | 17分 | 14% |

- 总题量：22-24题（12套卷范围）
- 总分：120分
- 考试时长：150分钟
- 作文固定50分，二选一

## 三、维度二：核心考点与知识分布

### 按板块梳理，每个板块输出「考点标签云」+「文字说明」

### 3.1 积累与运用板块

考点标签（tag样式）：
- 字音字形辨析（具体列出本卷考查的字词）
- 词语运用辨析（具体列出辨析的词组）
- 语法分析（短语类型/主干提取/词性辨析/标号作用/句间关系/病句——本卷考了哪几项）
- 文学文化常识（具体列出考查的作家/作品/文化知识）
- 整本书阅读/名著探究（具体列出涉及的名著+考查方式）
- 理解性默写6空（具体列出涉及的篇目）

文字说明：
- 积累运用的统一情境是什么（如"沈阳振兴""革命文物""清明风筝"等）
- 名著阅读的考查方式（简单识记/情境对话/探究策略/人物精神分析/坐标图匹配）

### 3.2 古诗文板块

考点标签：
- 古诗对比（课内篇目 vs 课外篇目，标注作者和主题）
- 文言文对比（课内篇目 vs 课外篇目，标注作者和主题）
- 实词辨析（列出具体考查的实词/虚词）
- 文言文翻译
- 断句
- 对比分析主题（治学/义利/思乡/报国等）
- 默写涉及的所有篇目

文字说明：
- 古诗对比的类型：同主题异体裁 / 同词牌异主题 / 同作者异时期 / 和诗
- 文言文对比的主题归类
- 课外文言文的出处和难度评估

### 3.3 现代文阅读板块

考点标签：
- 非连续性文本（主题+材料数量+任务类型）
- 记叙文（篇名+作者+主题概述）
- 议论文 或 说明文（篇名/主题概述）

文字说明（每类现代文单独一段）：
- **非连续性文本**：材料主题 + 考查方向（信息判断/信息提取/活动方案/辩论/倡议书）
- **记叙文**：选文概述（人物/情节/主题）+ 考查方向（人物形象/情节作用/词语赏析/语言特点/标题含义/写法鉴赏）
- **议论文**：论点 + 考查方向（论证思路/论证方法/语言改写/观点评价）
- **说明文**（如有）：说明对象 + 考查方向（说明思路/说明方法/语言分析）

注意：12套卷中，第三篇现代文为议论文（多数）或说明文（少数如皇姑区），需准确判断。

### 3.4 写作

考点标签：
- 题目一的类型和题目
- 题目二的类型和题目
- 二选一
- 600字以上

文字说明：
- 两道作文题分别考查什么能力（情感叙事/思辨议论/想象创造）
- 审题要点

## 四、维度三：逐题映射与能力评估

### 4.1 逐题映射表

| 题号 | 分值 | 考点 | 能力维度 | 教材定位 |
|------|------|------|----------|----------|

**能力维度**分类（语文特有）：
- 识记·辨析（字音字形/文学常识/默写）
- 理解·语境判断（词语运用/文言实词）
- 理解·翻译（文言文翻译）
- 理解·语法分析（语法题/断句）
- 分析·概括（人物形象/情节梳理/信息提取/论证思路）
- 分析·鉴赏（词语赏析/诗歌鉴赏/论证方法/说明方法/对比手法）
- 分析·比较（古诗对比/文言文对比）
- 分析·逻辑（论证思路/说明思路）
- 综合·表达（活动方案/倡议书/推荐语/改写）
- 综合·感悟（行为理解/人生感悟/多重含义）
- 表达·构思·写作（作文）

**教材定位**：
- 积累运用：七—九年级常用字积累 / 词语专题 / 语法知识专题 / 文学常识汇总
- 名著：标注具体名著名称和对应年级（如《水浒传》九上）
- 默写：标注具体篇目名称
- 古诗文：标注课内篇目名称+课外篇目出处
- 现代文：标注阅读专题类型（记叙文/议论文/说明文/非连续性文本）
- 作文：作文训练（情感/思辨）

### 4.2 四模块风险评估卡（grid-2双栏布局）

每个模块一张卡片：

**模块A：积累运用**
- 覆盖题位 + 分值
- 风险等级：低/中/高
- 失分点：具体列出本卷的易错题和原因
- 提分抓手：针对性训练建议

**模块B：古诗文阅读**
- 同上结构
- 重点标注：课外文言文翻译难点 + 断句难点 + 对比分析要点

**模块C：现代文阅读**
- 同上结构
- 重点标注：记叙文哪道题最容易丢分 + 议论文/说明文答题规范

**模块D：写作**
- 同上结构
- 重点标注：两道作文题各自的审题陷阱 + 立意建议

## 五、维度四：命题特征与趋势研判

### 输出格式

开头一句话概括本卷命题逻辑特征（如"情境整合+地域嵌入+价值引领+思辨导向"）。

然后逐条提炼命题DNA（编号 DNA-1 到 DNA-N，通常6-8条），每条包含：
- **DNA编号+标题**（加粗）
- 具体说明（哪道题体现了这个特征，怎么体现的）

### 命题DNA常见类型（12套卷归纳）

| DNA类型 | 说明 | 出现频率 |
|---------|------|----------|
| 情境化整合命题 | Q1-Q3在统一语段中整合考查 | 12/12 |
| 辽宁地域深度嵌入 | 沈阳/辽宁本地素材融入情境 | 10/12 |
| 课内外对比阅读 | 古诗对比+文言文对比 | 12/12 |
| 名著阅读策略化/创新化 | 超越简单识记，考查阅读策略 | 8/12 |
| 社会热点嵌入 | 新质生产力/AI/碳中和/传统文化复兴 | 10/12 |
| 记叙文文学性强 | 选文来自名家/名刊，情感细腻 | 12/12 |
| 议论文/说明文贴近生活 | 网络语言/倍速文化/地月导航等 | 12/12 |
| 写作思辨化趋势 | 二选一中至少一道偏思辨 | 10/12 |
| 红色文化/传统文化引领 | 革命文物/古典文化/非遗 | 8/12 |
| 任务驱动型非连续性文本 | 辩论/倡议书/活动方案/调研报告 | 12/12 |

末尾一段「趋势判断」：基于本卷特征，预测中考命题方向。

## 六、维度五：提分策略与落地方案

### 6.1 优先级建议表（按提分效率排序）

| 优先级 | 任务 | 目标 | 建议周期 |
|--------|------|------|----------|
| P1 | 作文模板训练（情感类+思辨类各一套） | 50分题稳定38+分 | 每天1篇，交替两类型 |
| P2 | 古诗文默写+课内文言文虚词过关 | 23分板块丢分≤4分 | 每日15分钟 |
| P3 | 记叙文阅读答题模板固化 | 17分板块稳定12+分 | 5天专项 |
| P4 | 议论文/说明文阅读答题模板固化 | 11分板块稳定8+分 | 5天专项 |
| P5 | 名著整本书阅读+文学常识过关 | 5分名著题稳定拿满 | 3天集中 |

### 6.2 易错预警表

| 高频易错点 | 典型表现 | 纠偏策略 |
|------------|----------|----------|

语文高频易错点类型（12套卷归纳）：
- **语法分析综合题**：主干提取错误/句间关系判断错/短语类型混淆
- **文言文一词多义**：以/之/而/其/于/为/乃 的多义辨析
- **名著细节**：格列佛游记四次远航顺序/水浒传绰号混淆/简爱情节错位
- **记叙文人物形象概括不全**：只写2-3点，实际需4-5点
- **议论文论证思路表述混乱**：不分层次，笼统概括
- **古诗对比只写共同点**：忽略描写角度/情感基调/表现手法的差异
- **课外文言文关键实词**：不会迁移课内义项到课外语境
- **非连续性文本信息判断**：被"只要…就…"等绝对化表述迷惑
- **作文立意泛化**：关系类话题只写单向，缺乏双向互动
- **默写错别字**：理解性默写会背但写错字（如"燕然未勒归无计"的"勒"）

### 6.3 目标分数规划表

| 分数档 | 积累+默写（17分） | 古诗文阅读（17分） | 现代文阅读（36分） | 作文（50分） |
|--------|-------------------|-------------------|-------------------|-------------|
| 冲刺105+ | 15-17分 | 14-17分 | 30-36分 | 42-50分 |
| 稳定90-104 | 13-15分 | 11-14分 | 25-30分 | 38-42分 |
| 保底75-89 | 11-13分 | 8-11分 | 20-25分 | 33-38分 |

### 6.4 核心答题模板（语文独有维度）

这是语文 Skill 区别于数学/物理的最重要部分。每套卷的维度五必须包含3-5个针对本卷考查方向的答题模板。

#### 常备模板库（根据本卷实际考查选用）

**"人物形象分析"分段法：**
1. 逐段找人物行为/语言/心理 → 提炼品质关键词
2. 合并同类项，归纳为3-5个品质维度
3. 每个品质维度配一个文中细节作为证据

**"词语赏析"三步法：**
1. 解释词语本义
2. 分析语境义/修辞效果（化无形为有形/化抽象为具象）
3. 点明表达效果（生动形象地写出了__，表现了__的情感）

**"关键词多重含义"分层法：**
1. 表层义：在文中具体指__
2. 深层义：象征/暗示了__
3. 主题义：表达了__（与文章中心的关联）
4. 拓展义：也可理解为__（普遍意义）

**议论文"论证思路"格式：**
- 首先……引出话题/提出论点 → 接着从……角度……（方法+内容） → 然后…… → 最后……

**议论文"论证方法分析"模板：**
- 运用了__论证方法，将__比作/列举__的事例，__地论证了__

**说明文"语言特点"分析模板：**
- 运用了__修辞/表达方式，将__比作__，生动形象地说明了__的特点，体现了说明文语言__的特点

**"以小见大"推荐语仿写模板：**
- __（四字概括特色），__（四字概括深度），《文章名》以小见大，__（一句话点明写法），于__中见__，于__中见__。

**"神态/动作描写"心理分析三步法：**
1. 描写了__（具体神态/动作）
2. 反映了人物__的心理/情感
3. 体现了人物__的性格特点/精神品质

**古诗对比鉴赏模板：**
1. 题材/主题差异
2. 描写手法差异（视听结合/动静结合/虚实结合等）
3. 情感基调差异
4. 相同点（词牌特征/共性情感/时代背景）

## 九、分析流程 Checklist

- [ ] 1. 确认试卷结构（22/23/24题？四大板块分值？）
