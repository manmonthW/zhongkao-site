六 · 命题趋势与规律

规律1：Q16固定考中国古代史，Q17固定考中国近现代史

8套卷无一例外。Q16主题变化(制度/文化/科技/民族交融/统一)，但板块固定。Q17必含"洋务→戊戌→辛亥→新文化→五四→中共成立"主线的部分节点。

规律2：Q19论述题固定6分，分层评分，主题围绕"大观点"

8个论述题全部是6分、4级评分。出题模式固定：给3-4个史实选项→选2个论证→开头亮观点→两段论据→总结回扣。结构比内容重要——即使论据平庸，格式完整也能拿4分。

规律3："历史解释vs历史事实"几乎必考

8套卷中6套出现该方法论题。判断标准：含主观评价词（"推动了""标志着""促进了"）的是"历史解释"，纯客观陈述时间地点事件的是"历史事实"。这2分几乎白送。

规律4：图片/情境题占选择题30%-40%

文物图、地图、数据图表、手抄报、辩论赛、歌词、论文标题……图片和新情境是命题创新的主阵地。但本质仍考知识点识别，不必被花哨包装迷惑。

七 · 统一备考行动方案

第一优先级：必拿分项（~45分）

A. 中国近代探索主线 → 默写到滚瓜烂熟（预计覆盖15-20分）
  1. 鸦片战争(1840) → 《南京条约》→ 开始沦为半殖民地
  2. 第二次鸦片战争(1856-1860) → 英法联军火烧圆明园
  3. 洋务运动(1860s-1895) → "自强""求富" → 甲午战败标志失败
  4. 甲午战争(1894) → 《马关条约》→ 大大加深半殖民地化
  5. 戊戌变法(1898) → 百日维新 → 谭嗣同就义
  6. 辛亥革命(1911) → 推翻帝制 → 建立中华民国
  7. 新文化运动(1915) → 《新青年》→ 民主与科学
  8. 五四运动(1919) → "外争主权内除国贼" → 新民主主义革命开端
  9. 中共一大(1921) → 开天辟地
  10. 井冈山道路 → 农村包围城市、武装夺取政权
  11. 长征(1934-1936) → 遵义会议 → 红军保存了革命火种
  12. 抗日战争(1937-1945) → 全民族抗战
  13. 解放战争(1946-1949) → 辽沈/淮海/平津 → 渡江战役
  14. 开国大典(1949.10.1) → 新中国成立
B. 论述题"万能论据库"（6分）

以下10个论据可覆盖8种论述方向：

  1. 商鞅变法 → 制度创新/改革推动(秦国由弱变强)
  2. 秦统一六国 → 统一大势/制度创新(第一个统一多民族封建国家)
  3. 四大发明(造纸/印刷/火药/指南针) → 中华智慧/文明交流(推动欧洲社会转型)
  4. 文艺复兴 → 思想文化/文明交流(冲破封建神学束缚)
  5. 明治维新 → 改革创新(日本由封建→近代化)
  6. 法国大革命 → 人民群众/民族独立(推翻封建君主专制)
  7. 五四运动 → 人民群众(工人阶级登上政治舞台)
  8. 联合国家宣言 → 合作共赢(26国联合反法西斯)
  9. 港澳回归 → 统一大势/中国智慧(一国两制成功实践)
  10. 改革开放 → 改革创新(中国经济腾飞，GDP世界第二)
C. 论述题固定答题模板（保底4分）

第一段（观点）："我认为[主题]。下面用两个史实加以论证。"
第二段（史实1）："[时间]，[人物/国家][做了什么]，[产生了什么影响]。这说明[回扣主题]。"
第三段（史实2）：同上格式。
第四段（总结）："综上所述，[重申观点]，[主题]是推动[社会进步/文明发展]的重要力量。"

第二优先级：稳拿分项（~15分）

D. 古代制度线 + 科技文化线
  • 制度线：分封制(西周)→郡县制(秦)→三省六部(隋唐)→行省制(元)→废丞相设内阁(明)→军机处(清)
  • 科技线：造纸(蔡伦)→印刷(毕昇)→火药(唐)→指南针(宋)→本草纲目(李时珍)→天工开物(宋应星)
  • 交融线：孝文帝改革→唐蕃和亲(文成公主)→元朝回族形成→清代册封达赖班禅
E. 辽宁地方史（~5-9分）

参见第五部分清单。最少背7个知识点，在苏家屯式专题中可拿满9分。

第三优先级：世界史核心（~10分）

F. 世界史必备
  • 古代：两河流域(楔形文字/汉谟拉比法典)、古埃及(金字塔)、雅典民主、罗马法
  • 近代：文艺复兴→新航路→英国资产阶级革命(《权利法案》)→美国独立(1787宪法)→法国大革命→工业革命→马克思主义
  • 现代：一战→凡尔赛-华盛顿→二战(斯大林格勒转折)→冷战(杜鲁门/北约/华约)→经济全球化(WTO)→信息化
